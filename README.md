# 癸酉本《石头记》后二十八回 · 行文润色工程

把《癸酉本石头记》后二十八回的行文，按人民文学出版社《红楼梦》（中国艺术研究院红楼梦研究所校注，彩皮定本）前八十回的语言习惯重新润色一遍。

**先读这段，否则会误解本项目：**

- 癸酉本不是曹雪芹原稿，学界基本无争议地判定为现代续书。本项目**不主张**它是真本。
- 本项目也**不是**校勘本、不是学术整理本，是一次**语言层的改写实验**：保留癸酉本的情节、人物、回目、诗词，只把叙述与对白的用词、语气、句法往曹雪芹的方向调。
- 润色稿是**现代人写的仿作**，不是文物，也不是"还原"。请勿引用为原作。

## 项目规则

1. **回目不改**。原回目的生造词、错字（如"行狭义""大瘐岭"）一律保留，`polish.py` 对标题行硬保护。
2. **诗词不改**。标题诗、联句、曲词、批语一并原样保留，程序按诗块识别并跳过。
3. **只动行文**。叙述、对白、连接词、语气词、句长。

## 目录

```
source/     癸酉本后28回原文（从 PDF 抽取，未改动）
drafts/     规则初稿：全文 28 回，仅替换词汇与语气词，句长未动
polished/   人工精修稿（当前仅 ch081 节选）
data/       baseline.json（基线指标）、lexicon.tsv（替换词表）、changes.json（替换台账）
tools/      extract.py / build_baseline.py / polish.py / check_style.py
docs/       STYLE_GUIDE.md（语言规范）、METHOD.md（口径与方法）、验收报告.md
```

## 用法

```bash
python tools/extract.py  <guiyou.pdf> source/
python tools/build_baseline.py <hongloumeng.epub> data/baseline.json
python tools/polish.py   source/ drafts/
python tools/check_style.py source/ drafts/ --out docs/验收报告.md
```

只依赖标准库。抽取 PDF 时若未安装 `pypdf`/`PyMuPDF`，会回退到命令行 `workbuddy-pdf`。

## 效果（对基线）

| 指标 | 校注本前80回 | 癸酉本原文 | 规则初稿 |
|---|---|---|---|
| 罢+呢 占语气词比例 | 99.1% | 54.6% | **97.7%** |
| 吧（每万字） | 0.08 | 5.03 | **0.98** |
| 啊（每万字） | 0.12 | 4.47 | **0.98** |
| 吗（每万字） | 0.07 | 4.34 | **0.39** |
| 单用"咱"（每万字） | 0.16 | 5.37 | **0.30** |
| 便（每万字） | 36.00 | 14.83 | 14.82 |
| 一面（每万字） | 9.16 | 0.77 | 0.77 |
| 平均句长（字） | 23.8 | 31.5 | 31.5 |

语气词与人称已收敛到位；**「便」「一面」与句长三项规则改不动**，只能逐句重写，这就是 `polished/` 存在的原因。
