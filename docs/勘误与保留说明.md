# 勘误与保留说明

## 这份文档解决什么问题

癸酉本后二十八回的原稿有明确的文字问题：回目里有错字和生造词，批语里有误植，回前诗多数不合近体诗格律，正文里散着同音、形近的误植。

本项目对这些问题的处理**不是一律改正**，而是分开办：

- **回目、诗、词、批语**：一字不动，错的地方也留着。理由见下文第一节。
- **正文**：同音、形近的误植改正；其余改动属行文润色，不计入勘误。

凡是没改的地方，本文档逐条说明问题在哪、为什么保留。凡是改了的地方，本文档给出原稿与改后的对照。

---

## 一、一字未动、问题照旧的三类

### 1. 回目（28 条，585 字）

回目一律保留原稿面貌，包括错字。

**（1）明确错字 2 处**

| 回次 | 原稿 | 应为 | 说明 |
|---|---|---|---|
| 第九十五回 | 醉金刚风雨行**狭义** | 行**侠**义 | 「侠义」误作「狭义」，音同形近 |
| 第百回 | 邢岫烟魂断**大瘐岭** | 大**庾**岭 | 江西大庾岭，因「庾」「瘐」形近而误 |

**（2）生造词 6 处**

| 回次 | 原稿用词 | 问题 |
|---|---|---|
| 第八十一回 | 惜**昵近**公子做良媒 | 「昵近」不成词，疑为「昵就」 |
| 第八十二回 | 王熙凤病求**千翼方** | 「千翼方」于药名无考 |
| 第八十四回 | 薛宝钗**弥望霭烟缘** | 五字硬凑，语义不通 |
| 第八十五回 | 惭妙尼避情**乘游槎** | 「乘游槎」生造，槎为木筏，与情节不合 |
| 第百零六回 | **孤倔**王孙悬崖撒手 | 「孤倔」不成词，疑为「孤介」 |
| 第百零七回 | 贾宝玉**淡后事**今生 | 「淡后事」生硬，疑为「淡看后事」 |

保留的理由：回目是原稿的骨架，改一个字整回的身份就变了。读者需要知道哪一条回目有瑕疵，而不是拿到一份被悄悄修好的回目表。上表就是这份交代。

### 2. 诗（回前诗 28 首，984 字；正文引诗 4 处）

诗一律原样保留。但要说清楚：**癸酉本的回前诗形式上仿七绝，实际多数不守近体诗格律。**

按现代读音逐首检查韵脚平仄，28 首里有 7 首韵脚平仄相杂（近体诗要求押平声韵，一韵到底）：

| 回次 | 韵脚 | 平仄 |
|---|---|---|
| 第八十三回 | 吟／镜 | 平／去 |
| 第九十七回 | 空／忠／重／生 | 平／平／去／平 |
| 第百回 | 冢／空 | 上／平 |
| 第百零一回 | 楚／吾 | 上／平 |
| 第百零三回 | 衰／解 | 平／上 |
| 第百零四回 | 恨／分 | 去／平 |
| 第百零七回 | 汩／忽 | 上／平 |

另有数首韵脚虽同为平声，韵部却相隔，属出韵或宽韵通押，例如第八十二回「心／春」（侵韵与真韵）、第九十八回「惜／歔」（入声陌韵与平声鱼韵）。

这不是校订造成的，是原稿本来的样子。保留原样，是因为一旦替它改韵，就等于替作者重写——那是另一件事，不是「润色行文」。

正文中引用的前人诗（如第八十六回探春念的杜牧《清明》、第百零一回小鹊听到的王勃《送杜少府之任蜀州》）同样一字未改。

### 3. 批语（212 条，5,435 字）

批语一律原样保留，包括误植。

已知 1 处：

| 回次 | 原文 | 应为 | 处理 |
|---|---|---|---|
| 第九十回 | 贾蓉应该是**如梗在喉** | 如**鲠**在喉 | 保留原字 |

这一条曾经在校订中被改成「如鲠在喉」，复查时改回「如梗在喉」。批语是原稿的一部分，改它的字等于伪造批语。

批语的分布：行间批、回前批、回末批、方括号批，以及第百零八回何莉莉所附的「前八十回批语摘录」与「癸酉本版本备忘录」，全部照录。逐条核验见 [诗词批语回目核验.md](诗词批语回目核验.md)。

## 二、正文中已改正的原稿误植

正文允许润色，所以同音、形近的误植一律改正。已确认并改正的：

| 回次 | 原稿 | 改为 | 依据 |
|---|---|---|---|
| 第九十九回 | 园中**丫鬓**风流云散 | 丫**鬟** | 形近误植，指园中丫鬟 |
| 第百零七回 | 太太旧时**丫鬓** | 丫**鬟** | 同上 |
| 第百零七回 | 宝玉**饥肠漉漉** | 饥肠**辘辘** | 「漉漉」状湿润，饥肠当用「辘辘」 |
| 第百零七回 | 女丐抢去**强吞虎咽** | **狼吞虎咽** | 成语误植 |
| 第百零八回 | 要**阂府**全抄 | **阖府**全抄 | 「阂」「阖」形近 |

需要说明的是：第百零七回另有「地上积了厚厚棉絮」，第九十五回有「浑身湿漉漉的」——后者的「漉漉」用法正确，未改。判断依据是语义，不是字面。

## 三、哪些差异不算勘误

`source/` 与 `polished/` 之间的差异，绝大多数不是勘误，而是**按前八十回文风重写行文**的结果，例如：

- 句法：「被」改「叫／遭」、「把」改「将」、长句拆分、补「便」与「一面……一面」；
- 词汇：删语气词「吧／啊／吗」、改现代词（「一会儿」→「不多时」、「居然」→「竟」）；
- 标点：感叹号密度调整、对话与叙述之间的句读。

这些是项目的正题，逐条列进勘误表既无意义也读不完。若要完整对照，直接用 `git diff` 比较任意一回的 `source/` 与 `polished/`。

## 四、复现方式

```bash
# 核验回目、诗、批语是否一字未动（275 处，逐字比对）
python tools/verify_protected.py

# 生成核验报告
python tools/verify_protected.py --md docs/诗词批语回目核验.md
```

工具会输出逐回清单；任一处缺失即以退出码 1 报错，可用于 CI。
