## h044　变生不测凤姐泼醋　喜出望外平儿理妆

**场景类型**：口角争执（泼醋）／私谈（平儿理妆）

**开场**：`话说众人看演《荆钗记》，宝玉和姐妹一处坐着。林黛玉因看到《男祭》这一出上，便和宝钗说道：“这王十朋也不通的很，不管在那里祭一祭罢了，必定跑到江边子上来作什么！”`

—— 承接上回末（演戏），但**开场第一句就是暗刺**：宝玉今早刚跑出城去井台祭金钏，黛玉当场借戏文说他"不通"。宝钗`不答`，宝玉`回头要热酒敬凤姐儿`（避开了）。

**全书最漂亮的一次指桑骂槐，而且被骂的人不接话。** 曹雪芹不写黛玉"有意"，也不写宝玉"心虚"，只写一个答、一个躲。

**骨架**：
黛玉评《男祭》暗刺宝玉 → 贾母命众人轮流敬酒（尤氏、赖大妈妈、鸳鸯各来一轮）→ 凤姐酒沉离席 → 廊下遇小丫头回身就跑，审问、打嘴、拿簪子往嘴上戳 → 供出贾琏与鲍二家的 → 凤姐蹑脚至窗前，听见"阎王老婆死了就好了" → 回身先打平儿，踢门撕打鲍二家的 → 贾琏拔剑 → 凤姐跑到贾母处告状（改了口供）→ 贾琏持剑赶来 → 贾母骂贾琏，命他赔不是 → 平儿被李纨拉入园，宝钗劝 → 宝玉请平儿到怡红院，为她理妆 → 宝玉熨衣、洗手帕 → 次日贾琏赔不是 → 鲍二媳妇吊死，贾琏许二百两私了

**句法样本**：
1. `凤姐儿坐在小院子的台矶上，命那丫头子跪了，喝命平儿：“叫两个二门上的小厮来，拿绳子鞭子，把那眼睛里没主子的小蹄子打烂了！”`（一连串指令＋"喝命"；**权力靠命令的密度写**，不靠表情）
2. `说着，回头向头上拔下一根簪子来，向那丫头嘴上乱戳`（簪子本是首饰，用来戳嘴。**用最贴身的东西施暴**——全书凡写狠，都用"首饰变凶器"这一类落差）

**标签样本**：
- 笑道：`凤姐儿笑道：“这倒好了，我正想要打官司呢！”`（人死了，她笑；这一笑比骂更冷）
- 其他（啐骂）：`贾母啐道：“下流东西，灌了黄汤，不说安分守己的挺尸去，倒打起老婆来了！”`
- 其他（乜斜）：`贾琏乜斜着眼，道：“都是老太太惯的他，他才这样，连我也骂起来了！”`（"乜斜着眼"四字定住醉态与无赖）

**独有瞬间**：
> 宝玉忙走至妆台前，将一个宣窑瓷盒揭开，里面盛着一排十根玉簪花棒，拈了一根递与平儿。又笑向他道：“这不是铅粉，这是紫茉莉花种，研碎了兑上香料制的。”
>
> ……
>
> 宝玉因自来从未在平儿前尽过心——且平儿又是个极聪明极清俊的上等女孩儿——深为恨怨。今日是金钏儿的生日，故一日不乐。不想落后闹出这件事来，竟得在平儿前稍尽片心，亦今生意中不想之乐也。
>
> ……因见袭人等不在房内，尽力落了几点痛泪。

**点评**：这一回的结构是**两场暴力＋一场温柔**：凤姐打人、贾琏拔剑，然后宝玉给平儿理妆。

但关键在后面两段心理：**他给平儿理妆，一半为平儿，一半为自己**——白天没能好好祭金钏，这份心意要有处安放；而"尽力落了几点痛泪"时，他哭的其实是金钏，平儿以为他为自己哭。

**这是全书最复杂的一段"好心"：善举里有私心，私心里有真情，真情的对象还不对。** 曹雪芹一句辩解都不加，把三层全摊开。

**第二处（告状的艺术，全书最实用的一段）**：
> 凤姐儿哭道：“我才家去换衣裳，不防琏二爷在家和人说话……原来是和鲍二家的媳妇商议，说我利害，要拿毒药给我吃了治死我，把平儿扶了正。”

实情是那两人在咒她死、商量扶平儿；她说成"商议下毒"。**她告的不是实情，是能赢的版本。** 而贾母"都信以为真"。

**全书凡写"申冤"，一律写申冤者如何改造事实。** 这一条极重要：凤姐不是撒谎成性，她是**知道哪一种说法能调动权力**。

**第三处（贾琏赔不是，全场最好笑也最凉的一段）**：
> 贾琏听如此说，又见凤姐儿站在那边，也不盛妆，哭的眼睛肿着，也不施脂粉，黄黄脸儿，比往常更觉可怜可爱。想着：“不如赔了不是，彼此也好了，又讨老太太的喜欢了。”

**他赔不是的三个理由里，没有一个是"我错了"。** 第一个是"她现在这个样子好看"，第二个是"彼此好了"，第三个是"讨老太太喜欢"。

曹雪芹把这三条按顺序写出来，不加一句评论。**这比任何"贾琏是个薄情人"的判断都狠。**

## 本回横向观察

1. **回初第一句就能是暗刺。** 黛玉借《男祭》刺宝玉，两人都不点破。**全书凡"讽刺"，一律借第三方（戏文、典故、别人家的事）转手**，不直接对着人。

2. **暴力靠指令密度写，温柔靠器物细节写。** 前半回是一串命令（叫小厮、拿绳子、撕嘴、烙嘴、割肉），后半回是一排玉簪花棒、白玉盒胭脂、并蒂秋蕙。**同一回里两种笔法，泾渭分明。**

3. **申冤即改写事实。** 凤姐把"咒我死"升级成"下毒害我"。全书凡告状、诉委屈、传话，一律经过改造，且改造方向都是"更能调动权力"。

4. **赔不是的理由可以全是私利。** 贾琏三条理由无一条认错。**作者摆出来，不评。**

5. **好心可以有私心，且不必洗白。** 宝玉为平儿理妆，动机里掺着"补上金钏那一份"。**全书凡善举，几乎都掺着别的动机**（宝钗帮湘云设宴也掺着"我替你想得周到"的自我确认）。这是癸酉本完全没有的分寸。

6. **死的处理一律从简。** 鲍二媳妇吊死，全用对话交代：凤姐"死了罢了"，林之孝家的"许了他几个钱"，贾琏"许了二百两"，末了"入在流年帐上"。**一条人命，三段公文式的对话，写完。** 全书凡写死亡的社会处理，一律用这种冷笔（金钏之死同法）。

7. **时间推进词本回实录**：`一时`、`次日醒了`、`晚间`、`掌灯后方散`、`正说着`、`不在话下`。**`次日醒了，想昨日之事，大没意思`——用"醒了"作为时间刻度，同时带出悔意**，一箭双雕。

8. **叙述者本回显身 0 次。**
