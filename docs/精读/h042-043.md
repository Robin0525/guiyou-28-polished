## h042　蘅芜君兰言解疑癖　潇湘子雅谑补馀香

**场景类型**：私谈（宝钗"审"黛玉）／群戏（议画园子）／离别（刘姥姥辞行）

**开场**：`话说他姊妹复进园来，吃过饭，大家散出，都无别话。` —— 过渡句，十六个字，直接进下一场。全书凡"两场之间无戏"，一律这种极简过场，绝不硬凑。

**骨架**：
刘姥姥辞行，凤姐说贾母、大姐儿都病了 → 刘姥姥建议查祟书本子，彩明念《玉匣记》→ 凤姐请刘姥姥给大姐儿起名"巧哥儿" → 平儿、鸳鸯分别打点送行之物（鸳鸯还佯装要回锞子）→ 王太医诊贾母（贾母不叫放幔子）→ 宝钗叫黛玉到蘅芜苑，"你跪下，我要审你" → 宝钗自陈幼时也偷看杂书 → 黛玉垂头吃茶"心下暗伏" → 稻香村议惜春告假画园 → 黛玉"母蝗虫"、宝钗作注解 → 黛玉打趣"又要照着这样儿慢慢的画" → 宝钗开画具清单 → 黛玉"把他的嫁妆单子也写上了" → 宝钗按在炕上要拧脸，黛玉求饶时又提"教导我" → 宝钗放手，替她拢头发

**句法样本**：
1. `宝钗便坐了笑道：“你跪下，我要审你。”`（一句开场就进"审讯"模式，不铺垫、不解释来意；全书凡两人独处谈话，一律第一句定调）
2. `黛玉道：“论理一年也不多。这园子盖才盖了一年，如今要画自然得二年工夫呢。又要研墨，又要蘸笔，又要铺纸，又要着颜色，又要……”`（五个"又要"，第五个故意断在这里，由众人接问。**顿住的地方就是笑点**）

**标签样本**：
- 笑道：`宝钗笑道：“我也不知道，听你说的怪生的，所以请教你。”`
- 冷笑道：`宝钗冷笑道：“好个千金小姐！好个不出闺门的女孩儿！满嘴里说的是什么？你只实说便罢。”`（"好个……好个……"两个反语起手，先贬身份再说事）
- 其他（央告）：`黛玉笑着忙央告道：“好姐姐，饶了我罢！颦儿年纪小，只知说，不知道轻重，作姐姐的教导我。”`

**独有瞬间**：
> 宝钗见他羞得满脸飞红，满口央告，便不肯再往下追问，因拉他坐下吃茶，款款的告诉他道：“你当我是谁，我也是个淘气的。从小七八岁上也够个人缠的。……后来大人知道了，打的打，骂的骂，烧的烧，才丢开了。”

**点评**：这是全书最重要的一次"降格"。宝钗本可以站在道德高地上训人，她却先说"**我也是个淘气的**"——先把自己变成同案犯，再劝。

**技术：批评之前，先交出自己的把柄。** 效果写在下一句：黛玉"垂头吃茶，心下暗伏，只有答应'是'的一字"——**全书黛玉唯一一次服软，不是被道理说服，是被"共犯"这个身份收买。**

后面还有两层，都被处理得极轻：
- 黛玉求饶时说"作姐姐的教导我"，宝钗"忽听他又拉扯前番说他胡看杂书的话，便不好再和他厮闹"——**黛玉把"审"这件事又点了一次，宝钗立刻收手。两个人都在给对方递台阶。**
- 最后宝钗说"我替你把头发拢一拢"，黛玉"果然转过身来"。**刚审完，立刻拢头发。一个动作把关系定了。**

而宝玉在旁边看着，"只觉更好看"，还后悔"不该令他抿上鬓去，也该留着，此时叫他替他抿去"。**三个人的心思，全在一个拢头发的动作里，谁都没说。**

**第二处（"母蝗虫"与宝钗的注解，全书写"刻薄"的最高技术）**：
> 黛玉忙笑道：“可是呢，都是他一句话。他是那一门子的姥姥，直叫他是个‘母蝗虫’就是了。”
>
> 宝钗笑道：“……更有颦儿这促狭嘴，他用‘春秋’的法子，将市俗的粗话，撮其要，删其繁，再加润色比方出来，一句是一句。这‘母蝗虫’三字，把昨儿那些形景都现出来了。”

**宝钗不批评黛玉刻薄，而是给她的刻薄做技术分析。** 一段话把"母蝗虫"三个字拆成一套修辞法（撮要、删繁、润色、比方），还评为"一句是一句"。

**这是全书最微妙的一处**：宝钗明知道这话刻薄，她既不说"你不该说"，也不跟着笑完了事，而是**把它抬到"文章作法"的层面**——抬得越高，越显得她也觉得这刀快。

## h043　闲取乐偶攒金庆寿　不了情暂撮土为香

**场景类型**：宴饮筹备（凑份子）／单线（宝玉私祭金钏）

**开场**：`话说王夫人因见贾母那日在大观园不过着了些风寒，不是什么大病，请医生吃了两剂药也就好了` —— 承接上回（贾母病），一句话了结，随即转"给凤姐做生日"。

**骨架**：
贾母提议"学那小家子大家凑分子" → 各人认捐：贾母 20、薛姨妈 20、邢王夫人各 16、尤氏李纨各 12 → 凤姐替李纨出、又把黛玉宝钗"派"给两位太太 → 赖大母亲打趣"这儿媳妇成了陌路人" → 鸳鸯、平儿、袭人等也凑 → 凤姐连赵姨娘、周姨娘也拉上（各 2 两）→ 共 150 余两 → 尤氏受命操办 → 尤氏点银，发现少了李纨那一分，凤姐赖账 → 尤氏把平儿、鸳鸯、彩云、周、赵的钱都退了 → 九月初二，宝玉一早穿素服出门 → 茗烟跟随出北门 → 水仙庵借香炉 → 井台上焚香，含泪施半礼 → 茗烟代祝 → 回府，玉钏独坐廊下垂泪 → 贾母盘问，宝玉编"北静王爱妾没了"

**句法样本**：
1. `凤姐笑道：“老祖宗只把他姐儿两个交给两位太太，一位占一个，派多派少，每位替出一分就是了。”`（一句话把别人的钱派给别人出，还说得像替人打算；**凤姐的语言永远是"替你算账"的形式**）
2. `天亮了，只见宝玉遍体纯素，从角门出来，一语不发跨上马，一弯腰，顺着街就下去了。`（"一语不发""一弯腰""顺着街就下去了"——三个动作，**不交代去哪、不交代为什么**，读者跟他一起蒙）

**标签样本**：
- 笑道：`赖大之母忙站起来笑说道：“这可反了！我替二位太太生气。……这儿媳妇成了陌路人，内侄女儿竟成了个外侄女儿了。”`（全书下人对主子最放肆的一次打趣，且全场大笑）
- 其他（悄骂）：`尤氏因悄骂凤姐道：“我把你这没足厌的小蹄子！这么些婆婆婶子来凑银子给你过生日，你还不足，又拉上两个苦瓠子作什么？”`
- 其他（急）：`宝玉道：“糊涂东西，若可带了来，又不这样没命的跑了。”`

**独有瞬间**：
> 宝玉掏出香来焚上，含泪施了半礼，回身命收了去。茗烟答应，且不收，忙爬下磕了几个头，口内祝道：“我茗烟跟二爷这几年，二爷的心事，我没有不知道的，只有今儿这一祭祀没有告诉我，我也不敢问。只是这受祭的阴魂虽不知名姓，想来自然是那人间有一，天上无双，极聪明极俊雅的一位姐姐妹妹了。二爷心事不能出口，让我代祝：……你在阴间保佑二爷来生也变个女孩儿，和你们一处相伴，再不可又托生这须眉浊物了。”

**点评**：全书最动人的一段，而且**是仆人说给死人听的，不是宝玉说的。**

宝玉自己只有"含泪施了半礼"六个字，一句话没有。全部哀思由茗烟代说；而茗烟根本不知道祭的是谁（金钏），只猜"极聪明极俊雅的一位姐姐妹妹"。

**关键在最后那句祝词**：`保佑二爷来生也变个女孩儿……再不可又托生这须眉浊物了。` 这是宝玉一生的心愿，由一个不识字的小厮在井台上说出来。

**技术：最重要的表白必须由不知情的人说出。** 因为不知情，才说得直白；因为直白，才不肉麻。宝玉自己说这句话会像宣言，茗烟说就是祷词。

**第二处（同日两重时间）**：
这一天是凤姐生日，全府最热闹；宝玉跑到城外井台，祭一个投井的丫头。**同一日、同一府、两种时间，曹雪芹不写一句对比，只并置。**

回府时遇玉钏"独坐在廊檐下垂泪"，见他来便收泪说"凤凰来了"——**她哭的是姐姐，说的却是场面话。** 宝玉问"你猜我往那里去了"，玉钏"不答，只管擦泪"。

**她其实猜到了。** 作者不写她猜到，只写她不答。

**第三处（尤氏退钱，全书写"善"最不声张的一次）**：
> 尤氏临走时，也把鸳鸯二两银子还他……把彩云一分也还了他。见凤姐不在跟前，一时把周、赵二人的也还了他。他两个还不敢收。尤氏道：“你们可怜见的，那里有这些闲钱？凤丫头便知道了，有我应着呢。”

**尤氏在这回里做了一件全府只有她会做的事**：把凑来的钱一份份退给最出不起的人，而且**专挑凤姐不在的时候退**。她还说"只许你那主子作弊，就不许我作情儿"。

全书尤氏一直被写成"没嘴的葫芦"（第 68 回），这一回是她唯一一次主动。**曹雪芹写好人，一律写得像顺手，不像行善。**

## 本批横向观察

1. **批评之前先交出自己。** h042 宝钗"我也是个淘气的"。——全书凡有效劝说，一律先降格。h036 宝钗劝湘云也先说"你家里你又作不得主"（先替对方说破难处）。**这是同一个技术：把自己放到与对方同一层，再开口。**

2. **台阶要两个人一起递。** h042 黛玉提"教导我"，宝钗立刻收手；尤氏退钱专挑凤姐不在。**全书人和人的和解，从不靠一方认输，靠双方各退半步，且都不点明。**

3. **最重要的表白由不知情的人说。** h043 茗烟代祝"来生也变个女孩儿"。若宝玉自己说，是宣言；茗烟说，是祷词。**这条对润色极重要：癸酉本凡抒情一律由主角直说，正好相反。**

4. **同一天可以有两种时间。** h043 凤姐生日（宴）与井台私祭（丧）并置，一句对比不写。全书凡"乐中藏哀"，一律并置不点破（h040 刘姥姥大笑与黛玉"一牛耳"同回、h022 生日听戏与贾政悲谶同回）。

5. **“善”写得像顺手。** 尤氏退钱、平儿送刘姥姥旧衣（"衣裳虽是旧的，我也没大狠穿"）、鸳鸯佯装要回锞子再还她。**三处都写得像临时起意，不像刻意行善。**

6. **放肆只有下人说得出，且全场笑。** h043 赖大母亲"这儿媳妇成了陌路人，内侄女儿竟成了个外侄女儿了"。**全书对主子关系最锋利的一句评语，出自一个老仆妇的玩笑。** 与 h035 婆子评宝玉"呆气"同法。

7. **器物罗列本身是行文。** h042 宝钗那张画具清单（四十余项），不是炫学，是**用清单的长度写她的能干**。同一段里黛玉立刻用"炒颜色吃""嫁妆单子"两次拆台——**一庄一谐，靠清单的长度撑起笑点。**

8. **时间推进词本批实录**：`展眼已是九月初二日`、`一时`、`半日`、`刚说着`、`说着`、`不在话下`。**`展眼`在本批出现一次，用于跨日/跨旬**；`一时`仍是段内最短刻度。

9. **叙述者本批显身 0 次。** 两回全部由人物行动与对话推进。至此外部统计与逐回亲读仍完全一致。
