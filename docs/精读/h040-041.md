## h040　史太君两宴大观园　金鸳鸯三宣牙牌令

**场景类型**：宴饮（两宴）／园中巡览／谐谑

**开场**：`话说宝玉听了，忙进来看时` —— 承接上回末（小厮来叫），一句转到"商议给史湘云还席"。

**骨架**：
宝玉提分餐制（每人一高几、自斟壶）→ 次日开缀锦阁取高几与船 → 贾母簪菊，凤姐把一盘子花横三竖四插了刘姥姥一头 → 沁芳亭，刘姥姥说园子"比那画儿还强十倍" → 潇湘馆，刘姥姥让路走苍苔、咕咚一跤 → 贾母论"软烟罗"，凤姐认错 → 秋爽斋早饭，凤姐鸳鸯捉弄刘姥姥（象牙镶金筷、鸽子蛋、"老刘老刘食量大似牛"）→ 满场大笑 → 刘姥姥叹"一两银子，也没听见个响声儿就没了" → 探春房，板儿闹，刘姥姥打他一巴掌 → 坐船，黛玉说"留得残荷听雨声" → 蘅芜苑，贾母嫌太素净，命鸳鸯取三样陈设来换 → 缀锦阁行牙牌令 → 黛玉脱口"良辰美景奈何天"，宝钗回头看她 → 刘姥姥"大火烧了毛毛虫""花儿落了结个大倭瓜"

**句法样本**：
1. （群笑段，全引见下）
2. `贾母便拣了一朵大红的簪于鬓上。因回头看见了刘姥姥，忙笑道：“过来带花儿。”`（动作先行，一句话从自己转到别人；**先做，再说**，是全书对话的基本节拍）

**标签样本**：
- 笑道：`刘姥姥笑道：“我虽老了，年轻时也风流，爱个花儿粉儿的，今儿老风流才好。”`（自嘲里带自赞，一句话化解被捉弄）
- 其他（笑骂）：`贾母笑骂道：“小蹄子们，还不搀起来，只站着笑。”`
- 其他（叹）：`刘姥姥叹道：“一两银子，也没听见个响声儿就没了。”`

**独有瞬间（全书最著名的群笑段）**：
> 众人先是发怔，后来一听，上上下下都哈哈的大笑起来。史湘云撑不住，一口饭都喷了出来；林黛玉笑岔了气，伏着桌子叫“嗳哟”；宝玉早滚到贾母怀里，贾母笑的搂着宝玉叫“心肝”；王夫人笑的用手指着凤姐儿，只说不出话来；薛姨妈也撑不住，口里茶喷了探春一裙子；探春手里的饭碗都合在迎春身上；惜春离了坐位，拉着他奶母叫揉一揉肠子。地下的无一个不弯腰屈背，也有躲出去蹲着笑去的，也有忍着笑上来替他姊妹换衣裳的，独有凤姐鸳鸯二人撑着，还只管让刘姥姥。

**点评**：七个分号，七个人，七种笑法，**无一重复**；而且每一笑都只能是这个人：湘云豪（喷）、黛玉弱（岔气）、宝玉孩子气（滚）、贾母宠（搂着叫心肝）、王夫人克制（指着说不出话）、薛姨妈失态（喷茶到人裙上）、探春窘（饭碗合在别人身上）。

**这不是"七个人一起笑"，是七个人各自笑各自的。** 最后补两句：地下的"弯腰屈背""躲出去蹲着笑""忍着笑上来替人换衣裳"——**连笑声都分层**。末一句"独有凤姐鸳鸯二人撑着"——全场都倒了，只有主谋站着。

**这一段的技法可直接量化**：一次群体反应＝逐人一个专属动作＋顺序按座次＋结尾一句"唯一没倒的人"。

**第二处（伏笔藏在酒令里）**：
> 黛玉道：“良辰美景奈何天。”宝钗听了，回头看着他。黛玉只顾怕罚，也不理论。

《牡丹亭》《西厢记》在这时候是"禁书"。黛玉当众脱口，宝钗"回头看他"——**四个字，一句评语没有。** 这个"回头"要在第 42 回才兑现（宝钗审黛玉）。**全书伏笔的长度可以跨回，且埋的时候绝不提示。**

## h041　栊翠庵茶品梅花雪　怡红院劫遇母蝗虫

**场景类型**：日常起居（品茶）／谐谑（醉卧怡红院）

**开场**：`话说刘姥姥两只手比着说道：“花儿落了结个大倭瓜。”` —— 承接上回末句，**几乎逐字接住**，只多"比着"二字。全书回末/回初的接缝，常这样一字不改地叠一句。

**骨架**：
刘姥姥要木杯，鸳鸯取十个黄杨整抠套杯 → 茄鲞一段（凤姐口报菜谱）→ 刘姥姥认木头（"这一定是黄松的"）→ 乐起，宝玉捧杯敬王夫人 → 黛玉"如今才一牛耳" → 点心，贾母嫌螃蟹饺"油腻腻的" → 大姐儿与板儿换佛手柚子 → 栊翠庵，妙玉奉茶（老君眉、旧年蠲的雨水）→ 妙玉拉钗黛吃梯己茶，宝玉跟去 → 嫌成窑杯被刘姥姥用过，命搁在外头 → 宝玉讨来转赠刘姥姥 → 妙玉论水（五年梅花雪）→ 讥黛玉"竟是大俗人" → 刘姥姥醉入怡红院：撞画、照镜、开机关、睡宝玉床 → 袭人以百合香掩味、教她说辞

**句法样本**：
1. `只见迎面一个女孩儿，满面含笑迎了出来。刘姥姥忙笑道：“姑娘们把我丢下来了，要我碰头碰到这里来。”说了，只觉那女孩儿不答。刘姥姥便赶来拉他的手，“咕咚”一声，便撞到板壁上，把头碰的生疼。细瞧了一瞧，原来是一幅画儿。`（**先反应，后揭真相**；顺序一倒，笑点全无）
2. `我们成日家和树林子作街坊，困了枕着他睡，乏了靠着他坐，荒年间饿了还吃他，眼睛里天天见他，耳朵里天天听他，口儿里天天讲他`（四个"他"、五个排比，把树当人；**刘姥姥的语言一律是对句或排比**）

**标签样本**：
- 笑道：`刘姥姥笑道：“好是好，就是淡些，再熬浓些更好了。”`（一句把妙玉五年的雪水降成"淡茶"，全场笑，她自己不知道笑点在哪）
- 冷笑道：`妙玉冷笑道：“你这么个人，竟是大俗人，连水也尝不出来。”`
- 其他（刻薄）：`黛玉笑道：“当日圣乐一奏，百兽率舞，如今才一牛耳。”`

**独有瞬间**：
> 妙玉忙命：“将那成窑的茶杯别收了，搁在外头去罢。”宝玉会意，知为刘姥姥吃了，他嫌脏不要了。
>
> （后文）妙玉道：“幸而那杯子是我没吃过的，若是我吃过的，我就砸碎了也不能给他。”

**点评**：**一个"嫌脏"写得比任何形容都狠。** 成窑杯是宝物，因刘姥姥用过就要扔；而且她明说"若是我吃过的，我就砸碎了也不能给他"——不是嫌杯子脏，是嫌人。

妙玉的"洁"在这里第一次露出本质：**不是干净，是等级。** 作者一句话不评，只让宝玉"会意"。

**第二处（黛玉最刻薄的一句，且当面说）**：
> 黛玉笑道：“当日圣乐一奏，百兽率舞，如今才一牛耳。”

把"百兽率舞"改成"一牛"。**这句话是对宝玉说的，不是背后说，也不是心里想。** 全书黛玉的刻薄多数有对象、有场合，这一处最冷——她笑的是一个刚在她屋里摔过跤、被全府取乐的七十多岁老人。

曹雪芹没有为黛玉辩护，也没有惩罚她。**第 42 回宝钗"审"她，审的就是这一类话。**

**第三处（醉卧怡红院，技术核心是"错认三连"）**：
> 只见他亲家母也从外面迎了进来……他亲家只是笑，不还言……便心下忽然想起：“常听大富贵人家有一种穿衣镜，这别是我在镜子里头呢罢？”

先以为是亲家母（画），再以为是亲家母（镜），最后自己推出来是镜子。**三次错认，一次比一次接近真相，全靠她自己想。** 作者一句解释都不给。

## 本批横向观察

1. **群体反应＝一人一个专属动作。** h040 七人七笑，无一重复，且顺序按座次，末句点出"唯一没倒的人"。**这是全书群戏的基本算法**，癸酉本一律"众人都笑了""大家称奇"，一句了事。

2. **先反应，后真相。** h041 刘姥姥撞画、照镜，两处都是先写她的动作和台词，最后才揭"是画儿""是镜子"。**顺序不可倒，一倒就没有喜剧。**

3. **伏笔可以跨回，且埋时不提示。** h040 黛玉说"良辰美景奈何天"，宝钗只"回头看着他"，四个字。第 42 回才兑现。**全书没有一句"这为后文伏线"式的自我提示。**

4. **贫富差用"换算"写，不用形容。** 刘姥姥把一顿螃蟹换算成"够我们庄家人过一年"（h039）、把一两银子的鸽子蛋换算成"没听见个响声儿"（h040）、把软烟罗换算成"我们想他作衣裳也不能，拿着糊窗子"（h040）。**三次换算，一次比一次狠，且全部由她本人算。**

5. **"洁"即等级。** h041 妙玉扔成窑杯。全书凡写"讲究"，背后都是"谁能碰谁"。**这一层癸酉本完全没有**——它写富贵只写器物贵，不写器物背后的排斥。

6. **刻薄要当面，且不解释。** h041 黛玉"一牛耳"、h040 凤姐鸳鸯捉弄刘姥姥。**作者从不给刻薄加辩解，也不在当场惩罚。** 报应留到后面（第 42 回宝钗审黛玉）。

7. **时间推进词本批实录**：`次日清早`、`说笑之间`、`一时`、`须臾`、`当下`、`一时又见`、`及至`、`不在话下`。**`须臾`在本批出现一次（乐止），是全书少数几个"极短时间"的文言词**，只用于音乐、仪式这类有明确起止的段落。

8. **叙述者本批显身 0 次。** 两回全部由人物行动推进。至此外部统计与逐回亲读仍完全一致：**80 回 8 处显身，全部落在换轨处。**
