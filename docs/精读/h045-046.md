## h045　金兰契互剖金兰语　风雨夕闷制风雨词

**场景类型**：私谈（钗黛和解）／独处（秋窗风雨夕）／杂事（诗社经费、赖家摆酒）

**开场**：`话说凤姐儿正抚恤平儿，忽见众姊妹进来，忙让坐了，平儿斟上茶来。` —— 承接上回，"抚恤平儿"四字收上回的泼醋，随即转新事。

**骨架**：
探春来请凤姐作"监社御史"、又替惜春要画具 → 凤姐当场戳破"分明是叫我作个进钱的铜商" → 李纨与凤姐对嘴，明着为平儿报仇 → 赖嬷嬷进来说孙子选了州县官、要摆三日酒 → 赖嬷嬷教训孙子"你那里知道那'奴才'两字是怎么写的" → 凤姐要撵周瑞家的儿子，赖嬷嬷劝止（改打四十棍）→ 凤姐命人找旧画具送园 → 宝钗夜作针线至三更 → 秋分后黛玉嗽疾复发 → 宝钗来望，论药（建议燕窝粥）→ 黛玉自陈"只当你心里藏奸"，认错 → 宝钗"咱们也算同病相怜"，允每日送燕窝 → 雨夜，黛玉作《秋窗风雨夕》→ 宝玉蓑衣斗笠来访，黛玉先说"渔翁"、又失口说"渔婆" → 黛玉夺诗烧了，宝玉说"我已背熟了" → 宝玉持玻璃绣球灯回去 → 蘅芜苑婆子冒雨送燕窝，顺口说夜局 → 黛玉枕上感念宝钗、又羡她有母兄

**句法样本**：
1. `凤姐儿笑道：“你们别哄我，我猜着了：那里是请我作监社御史，分明是叫我作个进钱的铜商！”`（一句戳破来意，且用"进钱的铜商"这种粗词——**凤姐判断人事，一律用生意词**）
2. `黛玉笑道：“我不要他。戴上那个，成个画儿上画的和戏上扮的渔婆了。”及说了出来，方想起话未忖夺，与方才说宝玉的话相连，后悔不及，羞的脸飞红，便伏在桌上嗽个不住。`（**先出口，后自觉**——这个顺序写羞最准；若写成"想到此节便不肯说"，全没了）

**标签样本**：
- 笑道：`宝钗笑道：“将来也不过多费得一副嫁妆罢了，如今也愁不到这里。”`
- 其他（认错）：`黛玉叹道：“你素日待人，固然是极好的，然我最是个多心的人，只当你心里藏奸。”`
- 其他（讨饶）：`凤姐忙笑道：“好嫂子，赏我一点空儿。你是最疼我的，怎么今儿为平儿就不疼我了？”`

**独有瞬间（全书最重要的一次认错）**：
> 黛玉叹道：“你素日待人，固然是极好的，然我最是个多心的人，只当你心里藏奸。从前日你说看杂书不好，又劝我那些好话，竟大感激你。往日竟是我错了，实在误到如今。”
>
> 宝钗道：“这样说，我也是和你一样。”

**点评**：认错认得极彻底——不是"我误会你了"，是"**只当你心里藏奸**"，把自己的偏见原话端出来。

而宝钗的回答是这一段的枢纽：`我也是和你一样。` 黛玉立刻反驳，列出四条（有母亲、有哥哥、有买卖地土、有房有地），宝钗只回一句：`将来也不过多费得一副嫁妆罢了。`

**这是全书最险的一句玩笑**：把"你一无所有"这个最痛的点，用"嫁妆"两个字轻轻带过，还暗示她终要出嫁、离开这里。

**但接着宝钗说的是真话**：`你放心，我在这里一日，我与你消遣一日。你有什么委屈烦难，只管告诉我。`——**她给的是时间，不是东西。** 这是宝钗最不像"会做人"的一次，因为这句是真的。

**更深一层**：这场和解建立在**两人都承认自己有心机**的基础上——黛玉承认"我多心"，宝钗承认"我也是和你一样"。两个聪明人互相交底，才可能真和解。全书没有第二对人物这样和好过。

**第二处（诗的命运：写完就烧，但有人背下来了）**：
> 宝玉却不留心，因见案上有诗，遂拿起来看了一遍，又不禁叫好。黛玉听了，忙起来夺在手内，向灯上烧了。宝玉笑道：“我已背熟了，烧也无碍。”

**黛玉一生写诗，写完就烧或撕**（h038 螃蟹诗也是"一把撕了"）。而宝玉"已背熟了"——**她的作品没有刻本，只有一个人的记忆。**

这一句同时是全书对"文字能否留存"的一次暗答：**烧掉的是纸，留下的是人。**

**第三处（送灯，全书写"体贴"最有分寸的一段）**：
> 黛玉道：“跌了灯值钱，跌了人值钱？……怎么忽然又变出这‘剖腹藏珠’的脾气来！”

宝玉舍不得点好灯，怕人滑倒打破。黛玉反过来教训他"跌了灯值钱，跌了人值钱"。**两个人的体贴方式正好相反**：宝玉是"东西可以毁，人不能伤"，黛玉是"你连这个都不懂"。

**而这是全书黛玉唯一一次教宝玉做事。**

## h046　尴尬人难免尴尬事　鸳鸯女誓绝鸳鸯偶

**场景类型**：冲突（逼婚）／群戏（鸳鸯抗婚）

**开场**：`话说林黛玉直到四更将阑，方渐渐的睡去，暂且无话。` —— 承接上回末（黛玉失眠），一句收束，转新线。**全书换线一律用"暂且无话""不在话下"切断，不做过场。**

**骨架**：
邢夫人叫凤姐，说贾赦要讨鸳鸯 → 凤姐劝"别拿草棍儿戳老虎的鼻子眼儿"，被邢夫人抢白 → 凤姐立刻改口顺从，又设法避开（同车、不同行）→ 邢夫人到鸳鸯房里说亲，鸳鸯低头不语 → 平儿、袭人在园中遇鸳鸯 → 鸳鸯说"就是太太这会子死了……我也不能去" → 袭人、平儿出主意（说给宝玉/贾琏），被鸳鸯啐 → 鸳鸯嫂子来劝，被鸳鸯啐骂 → 宝玉藏身偷听（三人对话全被他听见）→ 四人到怡红院 → 贾赦放话"难出我的手心" → 鸳鸯拉嫂子到贾母跟前跪下，袖中剪子铰发立誓 → 贾母气骂王夫人 → 探春进来解围 → 凤姐凑趣"谁教老太太会调理人"

**句法样本**：
1. `鸳鸯听说，立起身来，照他嫂子脸上下死劲啐了一口，指着他骂道：“……什么‘好话’！宋徽宗的鹰，赵子昂的马，都是好画儿。什么‘喜事’！状元痘儿灌的浆儿——又满是喜事。”`（两个谐音歇后语连用："好画"谐"好话"、"灌浆"谐"喜事"；**全书唯一一次用谐音骂人**，且出自丫鬟之口）
2. `一面说着，一面左手打开头发，右手便铰。`（两个"一面"，动作分左右手，极短句急收；**暴力用最简洁的句子写**）

**标签样本**：
- 冷笑道：`鸳鸯红了脸，向平儿冷笑道：“这是咱们好，比如袭人、琥珀、素云、紫鹃、彩霞、玉钏儿、麝月、翠墨……这十来个人，从小儿什么话儿不说？”`（"冷笑"起，先叙旧情，再放狠话——**先把关系摆出来，反才不是一时之气**）
- 其他（骂）：`鸳鸯又是气，又是臊，又是急，因骂道：“两个蹄子不得好死的！”`
- 其他（气极）：`贾母听了，气的浑身乱战，口内只说：“我通共剩了这么一个可靠的人，他们还要来算计！”`

**独有瞬间**：
> 鸳鸯喜之不尽，拉了他嫂子，到贾母跟前跪下，一行哭，一行说……“我是横了心的，当着众人在这里，我这一辈子莫说是‘宝玉’，便是‘宝金’‘宝银’‘宝天王’‘宝皇帝’，横竖不嫁人就完了！就是老太太逼着我，我一刀抹死了，也不能从命！”
>
> 原来他一进来时，便袖了一把剪子，一面说着，一面左手打开头发，右手便铰。

**点评**：全书最烈的一次反抗，而且是**奴才反抗主子，当着全家的面**。两点技术：

**一、先跪下，再剪发。** 跪是礼，剪是决裂。**礼数做足了，反才立得住**——若一进门就闹，她只是个泼丫头；跪着剪发，她是个烈性人。

**二、"宝金""宝银""宝天王""宝皇帝"** ——借宝玉的名字作阶梯，一路升到皇帝，把"嫁人"从"给谁做妾"抬成"给谁都不行"。**这是全书最漂亮的一次排比式拒绝**，且用的是一个不识字的丫头的语言。

**三、剪子早就藏在袖里。** 作者把这句放在最后（"原来他一进来时，便袖了一把剪子"）——**先演，后揭准备**。与 h041 刘姥姥撞画、照镜同法：**动作在前，解释在后。**

**第二处（凤姐的两副面孔，本回最见功力）**：
> （前）凤姐儿听了，忙道：“依我说，竟别碰这个钉子去。……倒拿草棍儿戳老虎的鼻子眼儿去了！”
> （后，被抢白后）凤姐儿……连忙陪笑说道：“太太这话说的极是。我能活了多大，知道什么轻重？……老太太今儿喜欢，要讨今儿就讨去。”

**同一件事，前后两套话，间隔不到一页。** 而中间那一段心理（"倘或不依，太太是多疑的人，只怕就疑我走了风声"）把改口的理由交代得清清楚楚：**不是她怕，是她算准了顺着说才不吃亏。**

**这才是凤姐的本事**：她从不硬顶，一律先劝一句（尽到责任），被顶回来立刻转向，然后**用行动避开**（同车不同行、先走一步）。全书凡写凤姐办事，都是这个三段式。

**第三处（贾母错怪王夫人，探春解围）**：
> 探春有心的人，想王夫人虽有委曲，如何敢辩；薛姨妈也是亲姊妹，自然也不好辩的；宝钗也不便为姨母辩；李纨、凤姐、宝玉一概不敢辩；这正用着女孩儿之时……因此窗外听了一听，便走进来陪笑向贾母道：“这事与太太什么相干？老太太想一想，也有大伯子要收屋里的人，小婶子如何知道？”

**先列一遍"谁都不能说话"的名单，再让唯一能说的人开口。** 这一段的叙述逻辑本身就是内容：**在一个所有人都被身份堵住嘴的场合，只有庶出的三小姐能说这句公道话。**

## 本批横向观察

1. **认错要认得具体。** h045 黛玉不说"我误会了"，说"只当你心里藏奸"——把偏见原话端出。**全书凡有效的道歉，都具体到某一句错话。**

2. **和解要双向交底。** 黛玉承认多心，宝钗承认"我也是和你一样"。**单方认错只是服软，双方交底才是和解。**

3. **礼数做足，反才立得住。** h046 鸳鸯先跪下再剪发。**全书凡激烈反抗，必先完成礼数**（h033 贾母先"躬身"再啐贾政、h046 鸳鸯先跪后铰发）。

4. **先演，后揭准备。** 剪子藏在袖里，最后才说；刘姥姥撞的是画，最后才说。**作者的顺序永远是"效果→动作→解释"。**

5. **迁就要写出算计。** h046 凤姐改口，中间夹一段心理（"只怕就疑我走了风声"）。**全书凡人物转向，一律给出转向的利害计算**，不写"她怕了"。

6. **不能说话的人，要先列出来。** h046 探春解围前，叙述者把王夫人、薛姨妈、宝钗、李纨、凤姐、宝玉逐个排除。**这段"排除"不是废话，它是让探春那一句成立的前提。**

7. **诗写完就烧，但有人背下来。** h045。**全书对"文字留存"的态度：纸可以毁，记性不能。**

8. **时间推进词本批实录**：`至晚`、`一日`、`这日`、`至次日`、`一夜没睡`、`少刻`、`正说着`、`不在话下`。**`一夜没睡`四字作为时间刻度兼状态**（h046 鸳鸯），与 h044"次日醒了，想昨日之事"同法。

9. **叙述者本批显身 0 次。**
