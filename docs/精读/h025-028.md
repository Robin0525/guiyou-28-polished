## h025　魇魔法姊弟逢五鬼　红楼梦通灵遇双真

**场景类型**：梦幻神异／日常起居／群戏慌乱

**开场**：`话说红玉心神恍惚，情思缠绵，忽朦胧睡去，遇见贾芸要拉他，却回身一跑，被门槛绊了一跤，唬醒过来，方知是梦。` —— 承接上回末句（正是被门槛绊倒），一句解掉悬念，并明写"方知是梦"。

**骨架**：
红玉梦醒 → 宝玉隔纱屉子寻红玉，被海棠遮着看不真切 → 贾环抄经、彩霞劝 → 宝玉滚在王夫人怀里，贾环推蜡灯烫脸 → 黛玉来看，宝玉遮脸不让瞧 → 马道婆进府，向贾母讨海灯油 → 转赵姨娘房，五百两欠契换十个纸鬼 → 凤姐宝玉同时发病，凤姐持刀砍人 → 众人乱，薛蟠忙中酥倒 → 癞头和尚跛足道人持诵通灵玉 → 三十三日后愈 → 黛玉念阿弥陀佛，宝钗打趣姻缘

**句法样本**：
1. `一时又叫彩云倒杯茶来，一时又叫玉钏儿来剪剪蜡花，一时又说金钏儿挡了灯影。`（三个"一时又"，同一句式连用三次，写小人得势的琐碎。句式本身就是内容）
2. `独有薛蟠更比诸人忙到十分去：又恐薛姨妈被人挤倒，又恐薛宝钗被人瞧见，又恐香菱被人臊皮，——知道贾珍等是在女人身上做功夫的，因此忙的不堪。`（三"又恐"排比，破折号插一句解释，再收一句总结）

**标签样本**：
- 笑道：`凤姐三步两步的上炕去替宝玉收拾着，一面笑道：“老三还是这么慌脚鸡似的，我说你上不得高台盘。”`
- 其他（啐骂）：`被贾母照脸啐了一口唾沫，骂道：“烂了舌头的混帐老婆，谁叫你来多嘴多舌的！”`（"照脸啐了一口唾沫"，方向、力度、落点全给）
- 其他（鼻子里笑）：`赵姨娘听说，鼻子里笑了一声` —— 全书写轻蔑的固定动作，凡"鼻子里笑""鼻子里一笑"，都是瞧不起。

**独有瞬间**：
> 别人慌张自不必讲，独有薛蟠更比诸人忙到十分去：又恐薛姨妈被人挤倒，又恐薛宝钗被人瞧见，又恐香菱被人臊皮，——知道贾珍等是在女人身上做功夫的，因此忙的不堪。忽一眼瞥见了林黛玉风流婉转，已酥倒在那里。

**点评**：全府大乱，作者偏偏抽一笔写薛蟠。三"又恐"是正经的忙、真心的护，最后一句"已酥倒在那里"当场把这个正经戳破。**同一段里同时写一个人的可靠和下流，不解释、不评价。**

这是全书喜剧手法的标准式：先把人物写得可敬，再用一个生理反应把他打回原形。癸酉本写人物一律单向——坏人从头坏到尾。这类"半句翻案"的写法，是它完全没有的东西。

## h026　蜂腰桥设言传心事　潇湘馆春困发幽情

**场景类型**：日常起居／私谈（红玉线＋宝玉薛蟠线）

**开场**：`话说宝玉养过了三十三天之后，不但身体强壮，亦且连脸上疮痕平复，仍回大观园内去。` —— 承接上回（三十三日之约），一句话交代完，立刻转"这也不在话下"。

**骨架**：
红玉与佳蕙闲话（"千里搭长棚，没有个不散的筵席"）→ 红玉托佳蕙取笔，蜂腰桥与贾芸四目相对 → 贾芸访怡红院：隔纱窗→穿衣镜→碧纱橱，三层递进 → 坠儿传帕 → 潇湘馆，黛玉伸懒腰念"每日家情思睡昏昏" → 宝玉引《西厢》"若共你多情小姐同鸳帐"，黛玉哭 → 薛蟠假传贾政叫，骗宝玉出园 → 冯紫英来，只说"大不幸之中又大幸" → 黛玉扣怡红院门，晴雯不开 → 独立花阴下呜咽

**句法样本**：
1. `只见院内略略有几点山石，种着芭蕉，那边有两只仙鹤在松树下剔翎。一溜回廊上吊着各色笼子，笼着仙禽异鸟。上面小小五间抱厦，一色雕镂新鲜花样隔扇，上面悬着一个匾额，四个大字，题道是“怡红快绿”。`（全部"只见"起，由远及近、由外及内，一句一景，像镜头推）
2. `那贾芸一面走，一面拿眼把红玉一溜；那红玉只装着和坠儿说话，也把眼去一溜贾芸：四目恰相对时，红玉不觉脸红了，一扭身往蘅芜苑去了。`（"一面…一面"两两对举，冒号收束到"四目恰相对"，最后三个动作离场）

**标签样本**：
- 笑道：`薛蟠连忙打恭作揖陪不是……宝玉也无法了，只好笑问道：“你哄我也罢了，怎么说我父亲呢？”`（生气用"笑问"出口）
- 冷笑道：`红玉听了冷笑了两声，方要说话`（"冷笑了两声"——用"两声"计数的写法，全书仅此几处）
- 其他（使性子）：`晴雯偏生还没听出来，便使性子说道：“凭你是谁，二爷吩咐的，一概不许放人进来呢！”`

**独有瞬间**：
> 林黛玉听了，不觉气怔在门外……自己又回思一番：“虽说是舅母家如同自己家一样，到底是客边。如今父母双亡，无依无靠，现在他家依栖。如今认真淘气，也觉没趣。”一面想，一面又滚下泪珠来。正是回去不是，站着不是。

**点评**：`回去不是，站着不是` 六个字，把一个无家可归的人写完了。不用"孤苦""凄凉""寄人篱下"，只写她在门外两个方向都不能去。这是全书最省字的悲凉。

**结构上**：宝玉进怡红院这一段，是全书唯一一次详细写"外人眼中的怡红院"。隔纱窗、穿衣镜、碧纱橱三层，每层都有丫头挡一下。**同一个空间，用陌生人的眼睛重新量一遍**——这是曹雪芹写富贵的标准方法：不写富，写"别人进来找不到路"。

## h027　滴翠亭杨妃戏彩蝶　埋香冢飞燕泣残红

**场景类型**：日常起居／口角／独处抒情

**开场**：`话说林黛玉正自悲泣，忽听院门响处，只见宝钗出来了，宝玉袭人一群人送了出来。` —— 承接上回（黛玉正哭，院门开），且用"只见宝钗出来"造成第一次误会的**视觉证据**。

**骨架**：
黛玉见宝钗出来，闪身避开 → 芒种饯花，众人在园中，独不见黛玉 → 宝钗往潇湘馆，见宝玉进去，抽身回来 → 扑蝶至滴翠亭，听见红玉坠儿私语 → 使"金蝉脱壳"，推给黛玉 → 红玉信以为真，怕黛玉听见 → 凤姐山坡招手，红玉办事 → 红玉一段"奶奶"绕口令式回话 → 晴雯等讥她"爬上高枝儿" → 宝玉兜落花往花冢 → 听山坡哭声 → 痴倒

**句法样本**：
1. `宝钗便故意放重了脚步，笑着叫道：“颦儿，我看你往那里藏！”一面说，一面故意往前赶。`（"故意"两次，同一小段内重复；重复本身就是"演"的标记）
2. `红玉道：“平姐姐说：我们奶奶问这里奶奶好。原是我们二爷不在家，虽然迟了两天，只管请奶奶放心。等五奶奶好些，我们奶奶还会了五奶奶来瞧奶奶呢。五奶奶前儿打发了人来说，舅奶奶带了信来了，问奶奶好……”`（一段里八个"奶奶"，全靠称谓堆叠制造复杂度；凤姐评"这是四五门子的话呢"，作者借人物之口给自己的句式下批语）

**标签样本**：
- 笑道：`凤姐笑道：“怨不得你不懂，这是四五门子的话呢。”`
- 冷笑道：`晴雯冷笑道：“怪道呢！原来爬上高枝儿去了，把我们不放在眼里。”`
- 其他（皱眉回头）：`凤姐听说将眉一皱，把头一回，说道：“讨人嫌的很！得了玉的益似的，你也玉，我也玉。”`

**独有瞬间**：
> 宝钗在外面听见这话，心中吃惊，想道：“怪道从古至今那些奸淫狗盗的人，心机都不错。这一开了，见我在这里，他们岂不臊了……少不得要使个‘金蝉脱壳’的法子。”犹未想完，只听“咯吱”一声，宝钗便故意放重了脚步，笑着叫道：“颦儿，我看你往那里藏！”

**点评**：宝钗的"心机"全在**思考的完整度**上——三种后果、两层人情、一个对策，全想完，然后立刻执行。`犹未想完` 三字最狠：她其实已经想完了全部，作者偏说她没想完。不评价好坏，只把思维过程原样摊开，读者自己会怕。

**这一回真正的手法：同一件事写三遍视角。** 滴翠亭偷听——先写宝钗听见（外层），再写红玉坠儿推窗（内层），最后写红玉信以为真、转而担心黛玉（后果层）。三层写完，全书没有一句"宝钗很机敏""红玉很害怕"。

**又**：`满园里绣带飘飖，花枝招展，更兼这些人打扮得桃羞柳让，燕妒莺惭，一时也道不尽。` —— 整段写节日最盛，下一段立刻接"独不见林黛玉"。**盛景与缺席并置**，是这一回的结构骨架。

## h028　蒋玉菡情赠茜香罗　薛宝钗羞笼红麝串

**场景类型**：宴饮（冯紫英家酒令）／私谈

**开场**：`话说林黛玉只因昨夜晴雯不开门一事，错疑在宝玉身上。至次日又可巧遇见饯花之期，正是一腔无明正未发泄。` —— 承接上回，且**用一句因果总结把上一回的误会全部交代清楚**。全书凡遇需要"补账"处，都是这种一句带过的写法，绝不重述。

**骨架**：
宝玉听葬花吟恸倒，推及自身生死 → 追上黛玉，"既有今日，何必当初"，和好 → 王夫人处说丸药，宝玉扯"金刚丸" → 凤姐作证，黛玉羞他 → 黛玉裁衣不理，"理他呢，过一会子就好了" → 冯紫英家酒令，薛蟠"哼哼韵" → 蒋玉菡赠茜香罗，互换汗巾 → 元春赐节礼，宝玉与宝钗一样、黛玉不同 → 宝玉看宝钗褪红麝串发呆 → 黛玉称"呆雁"，帕子甩在宝玉脸上

**句法样本**：
1. `宝玉笑道：“两句话，说了你听不听？”黛玉听说，回头就走。宝玉在身后面叹道：“既有今日，何必当初！”`（一句钓住，八个字留住；对话推进不靠说明，靠对方"回头就走"再接一句）
2. `宝玉笑道：“我也跟着吃斋。”说着便叫那丫头“去罢”，自己先跑到桌子上坐了。`（"说着便"，动作紧接话，不加过渡）

**标签样本**：
- 笑道：`宝钗抿嘴笑道：“想是天王补心丹。”`（"抿嘴"是宝钗专属，全书统计中黛玉多"嗤的一声"，宝钗多"抿嘴"）
- 其他（母骂子）：`王夫人道：“扯你娘的臊！又欠你老子捶你了。”`（粗话出自主母之口，且带笑；全书凡长辈骂晚辈，粗而不恶）
- 其他（扎手笑）：`宝玉扎手笑道：“从来没听见有个什么‘金刚丸’。若有了‘金刚丸’，自然有‘菩萨散’了！”`（"扎手"是宝玉专属动作，全书多处）

**独有瞬间**：
> 黛玉便把剪子一撂，说道：“理他呢，过一会子就好了。”
>
> （宝钗来问，黛玉）道：“理他呢，过会子就好了。”
>
> （宝玉对宝钗）道：“理他呢，过一会子就好了。”

**点评**：同一句话，三次出现，字面几乎不改。第一次是黛玉**学宝玉的口吻**（她刚听宝玉对宝钗说过这话），第二次当着宝钗再说一遍，第三次宝玉说给宝钗听。

**一句解释都没有，语气已经把三个人此刻的站位全排好了。** 这是全书最精密的"复语"手法——用重复代替心理描写。癸酉本里人物一有情绪就直接说破，这类"借别人的话打人"的写法一句也没有。

**又**：`林黛玉笑道：“何曾不是在屋里的。只因听见天上一声叫唤，出来瞧了瞧，原来是个呆雁。”` —— 骂人不骂人，换成比喻；`将手里的帕子一甩，向宝玉脸上甩来` —— 动作却毫不含糊。**比喻出口，动作落地**，这是黛玉的标准句式。

## 本批横向观察

1. **"一句顶一段"的补账法。** h025 开头"唬醒过来，方知是梦"、h026 开头"养过了三十三天之后"、h028 开头"只因昨夜晴雯不开门一事"。三回都用**一句话把上一回全部交代完**，然后立刻进新场景。全书不重述前情，读者自己接。这是章回体的纪律，也是癸酉本最缺的（它每回开头都要把事情再说一遍）。

2. **同一段里写人的两面。** h025 薛蟠"三又恐"接"已酥倒"，是本批最典型的一处。**先立后破，不解释**。全书凡重要人物出场，几乎都配一次这样的自我拆台。癸酉本的人物一律单向。

3. **视角的三层写法。** h027 滴翠亭：宝钗听见→红玉推窗→红玉误信。一个事件写三遍，每次换一个人的所知范围。**读者知道得比任何一个人物都多**，这是全书制造张力的主要手段。

4. **重复句式当内容用。** h025"一时又叫…一时又叫…一时又说"（写琐碎）；h027 八个"奶奶"（写复杂度）；h028 三次"理他呢"（写站位）。三处都不是修辞装饰，**句式本身就在承担叙事功能**。这是最难模仿、也最容易被润色改坏的一层。

5. **"笑道"的分布再次验证按场景分区。** h025 全府慌乱（笑道几乎只出现在凤姐哄人、宝钗打趣两处）；h027 口角（冷笑道集中）；h028 酒宴（笑道密，但集中在薛蟠、云儿这类"活人"身上，宝钗只有一次"抿嘴"）。**单一阈值不可用，已第三次验证。**

6. **动作词是人物身份证。** 宝玉"扎手笑""猴上身去""扭股儿糖"；黛玉"嗤的一声笑""啐""摔帘子"；宝钗"抿嘴笑""装看不见"；凤姐"鼻子里笑""三步两步上炕"。**同一个人反复用同一组动作**，读者不看名字也知道是谁在说话。这是可统计的（`data/char_profiles.tsv` 目前只统计了句长和语气词，动作词未纳入，属实缺口）。

7. **时间推进的实词表（本批新增）**：`一时`（同段内）、`少时`、`展眼`、`堪堪`、`一时……一时`（并列）、`至次日`、`过了一日`、`一宿无话`。其中 **`一宿无话` 是回末收束的固定句**，本批出现 3 次（h025、h027、h028），全书高频。癸酉本几乎不用这个收束句。

8. **叙述者本批仅显身一次，且是极短的一句**：h028 开头"试想林黛玉的花颜月貌，将来亦到无可寻觅之时，宁不心碎肠断！"——"试想"二字引出。这是"代读者推想"，不是评论。**80 回中此类显身共 8 处，此为第 5 处，长度最短。**
