# 亲读笔记 · 第 14–17 回（含第十七、十八合回）

---

## h014 林如海捐馆扬州城 贾宝玉路谒北静王（约 7,600 字）

**场景**：丧葬＋日常（协理）

**开场**：`话说宁国府中都总管来升闻得里面委请了凤姐`——承接，且换个下人视角起。

**骨架**：来升告诫众仆（"有名的烈货"）→ 凤姐点卯、按数分班 → 迟到者打二十板、革一月银米 → 宝玉秦钟来坐 → 昭儿报林如海死讯 → 伴宿 → 出殡、四王路祭 → 北静王索见宝玉

**句法样本**
- `一面交发，一面提笔登记`
- 两句对文写忙：`刚到了宁府，荣府的人又跟到宁府；既回到荣府，宁府的人又找到荣府。`

**标签样本**：`冷笑道`（对迟到者 `我说是谁误了，原来是你！`）；`笑道`（对宝玉 `好长腿子，快上来罢。`）；喝命（`带出去，打二十板子！`）

**独有瞬间**：凤姐理事全用编号式口令——`这二十个分作两班……这四十个人也分作两班……这八个人单管监收祭礼`。**规则用数量词写，一个形容词不用。**

## h015 王凤姐弄权铁槛寺 秦鲸卿得趣馒头庵（约 8,000 字）

**场景**：巡览＋丧葬＋私谈

**开场**：`话说宝玉举目见北静王水溶头上戴着洁白簪缨银翅王帽`——承接上一秒，且从宝玉眼中给北静王穿戴。

**骨架**：赠苓香念珠 → 出城、庄户打尖、二丫头纺车 → 铁槛寺安灵 → 馒头庵净虚说张金哥案 → 凤姐索三千两 → 秦钟智能偷情、宝玉撞破

**句法样本**
- `一面极口称奇道异，一面理好彩绦，亲自与宝玉带上。`
- `凤姐听了这话，便发了兴头`——「发了兴头」四字写贪念起动，不写心理

**标签样本**：`笑道`（`我也不等银子使，也不做这样的事。`）；`半晌叹道`（净虚激将）；本回**无一处冷笑**

**独有瞬间**：`宝玉不知与秦钟算何帐目，未见真切，未曾记得，此系疑案，不敢纂创。`——叙述者假装不在场，还替自己立了个「疑案」档。

## h016 贾元春才选凤藻宫 秦鲸卿夭逝黄泉路（约 7,800 字）

**场景**：日常＋梦幻＋丧葬

**开场**：`话说宝玉见收拾了外书房，约定与秦钟读夜书。`

**骨架**：金哥自缢、守备子投河（三千两的后果）→ 贾政生辰、夏守忠降旨 → 合家惶惶 → 赖大报封妃 → 智能私逃、秦业气死 → 黛玉归来、掷鹡鸰串 → 凤姐「国舅老爷」一套假谦 → 赵嬷嬷说接驾 → 议省亲、丈量三里半 → 秦钟临终、鬼判放回

**句法样本**
- `因闻得元春喜信，遂昼夜兼程而进。`
- `一面平儿与众丫鬟参拜毕，献茶。`

**标签样本**：`笑道`（`国舅老爷大喜！`）；本回无冷笑；骂（`什么臭男人拿过的！我不要他。`）

**独有瞬间**：秦钟遗言 `以后还该立志功名，以荣耀显达为是`——把遗言写成对全书价值的反讽，一句便收，不许多说。

## h017 第十七至十八回（底本未分回，16,296 字）

**场景**：巡览（游园题对）＋宴饮（省亲）

**开场**：`话说秦钟既死，宝玉痛哭不已。`

**骨架**：葬秦钟 → 贾政游园试才（曲径通幽→沁芳→有凤来仪→稻香村→蘅芷清芬→红香绿玉）→ 迷路、玻璃大镜照人 → 黛玉铰香袋 → 采买女戏、妙玉入府 → 元宵归省、元妃垂泪、姊妹题诗、龄官拒戏 → 丑正三刻回銮

**句法样本**
- `一面走，一面说，倏尔青山斜阻。`
- `倏尔五色纱糊就，竟系小窗；倏尔彩绫轻覆，竟系幽户。`——「倏尔」只用于**视觉突变**，不用于时间跳接

**标签样本**：`笑道`（贾政 `我自幼于花鸟山水题咏上就平平`）；`冷笑道`（`怎么不妥？`）；`断喝`（`无知的业障！`）

**重大发现——叙述者显身的第四种姿势：自陈矛盾**

> `按此四字并"有凤来仪"等处，皆系上回贾政偶然一试宝玉之课艺才情耳，何今日认真用此匾联？……据此论之，竟大相矛盾了。诸公不知，待蠢物将原委说明，大家方知。`

作者先自己指出「这不合情理」，再解释原委。同回还有 `所以倒是省了这工夫纸墨，且说正经的为是`。
这是「先自曝其短，再补交代」的写法，与 h015「此系疑案，不敢纂创」、h016「一笔不能写到」同属一类：**叙述者只承认叙述的边界，从不替人物下判断。**

**独有瞬间**：`及至门前，忽见迎面也进来了一群人，都与自己形相一样，——却是一架玻璃大镜相照。`——把园林写成心理迷宫，迷路不是走错，是看见自己。

## 本批小结

1. **h014 的编号式口令**：凤姐治丧，全篇用「这二十个……这四十个……」分配职责，**制度用数量词表达**，不用「井井有条」这类评语。这是写「能干」最省字的办法。
2. **h015 的「疑案」与 h017 的「自陈矛盾」**：曹雪芹敢在正文里承认「我没看见」「这不合理」，然后补一句解释。**这一手现代小说都少有人敢用。**
3. **「发了兴头」这类四字写心理**：`发了兴头`、`心中大不自在`、`倒像针扎似的`——心理一律用短句外化，没有一处「他感到」。
4. **叙述者显身清单更新**：原记三种（呼告读者／交代编排／公开选材），本批新增第四种——**自陈矛盾**（h017）。
