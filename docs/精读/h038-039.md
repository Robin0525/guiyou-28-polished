## h038　林潇湘魁夺菊花诗　薛蘅芜讽和螃蟹咏

**场景类型**：宴饮（螃蟹宴）／诗社雅集

**开场**：`话说宝钗湘云二人计议已妥，一宿无话。湘云次日便请贾母等赏桂花。` —— 承接上回（夜拟菊花题），两句过场，直接进席。

**骨架**：
湘云请赏桂花 → 藕香榭摆席，竹案分设茶酒 → 贾母说枕霞阁旧事（幼时失脚落水、鬓角留窝）→ 凤姐把险事翻成吉兆（"好盛福寿的"）→ 凤姐剥蟹、让菜，廊下与鸳鸯琥珀平儿玩笑 → 平儿误把蟹黄抹在凤姐脸上 → 席散，众人各自消遣（黛玉钓鱼、宝钗掷桂蕊、迎春穿茉莉、探春李纨看鸥鹭）→ 分题，十二题勾名 → 各作菊花诗 → 李纨公评：咏菊第一、问菊第二、菊梦第三（黛玉夺魁）→ 众人互评警句 → 宝玉作螃蟹诗 → 黛玉也作，随即撕掉烧了 → 宝钗作"眼前道路无经纬，皮里春秋空黑黄"

**句法样本**：
1. `凤姐不等人说，先笑道：“那时要活不得，如今这大福可叫谁享呢！可知老祖宗从小儿的福寿就不小，神差鬼使碰出那个窝儿来，好盛福寿的。”`（把一件险事当场翻成吉兆——**凤姐式"转语"**：不说"您福大"，而说"这个疤是装福的容器"）
2. `宝玉又看了一回黛玉钓鱼，一回又俯在宝钗旁边说笑两句，一回又看袭人等吃螃蟹，自己也陪他饮两口酒。`（三个"一回又"，写他坐不住；全书写人物不安分，一律"一回…一回…"）

**标签样本**：
- 笑道：`鸳鸯笑道：“好没脸，吃我们的东西。”`（下人对主子奶奶说"好没脸"，全书仅此几处）
- 其他（笑骂）：`凤姐也禁不住笑骂道：“死娼妇！吃离了眼了，混抹你娘的。”`（粗话带笑，被骂的是平儿，骂的人是主子）
- 其他（自斟）：`黛玉道：“你们只管吃去，让我自斟，这才有趣儿。”`

**独有瞬间**：
> 平儿手里正掰了个满黄的螃蟹，听如此奚落他，便拿着螃蟹照着琥珀脸上抹来……平儿使空了，往前一撞，正恰恰的抹在凤姐儿腮上。凤姐儿正和鸳鸯嘲笑，不防唬了一跳，嗳哟了一声。众人撑不住都哈哈的大笑起来。

**点评**：一场大乱，起因只是琥珀一句"倒喝了一碟子醋"。**误中副车**——本来要抹琥珀，抹到了主子脸上。

这一笔在全书极罕见：**唯一一次下人失手冒犯了主子，而满场没有一个人惊慌。** 凤姐的反应是"笑骂"，鸳鸯的反应是"阿弥陀佛！这是个报应"。

等级在笑声里被暂时取消了，取消的时长就是这一顿螃蟹。**全书"以乐写等级"的典型**：等级最森严的地方，恰恰要在最放松的时刻才看得清——这一天凤姐给鸳鸯斟酒、被抹了脸还笑，**她不在等级里，读者才看得见等级。**

**第二处（黛玉唯一一次认输，且当场销毁证据）**：
> 宝玉看了正喝彩，黛玉便一把撕了，令人烧去，因笑道：“我的不及你的，我烧了他。”

全书黛玉从不认输（斗嘴、作诗、刻薄，一律要赢），只有这一次，而且处理方式极端：**不辩解，直接毁掉。** 曹雪芹不写她心里怎么想，只写"一把撕了"。

**第三处（评诗一段，全书写"文人相重"的唯一范本）**：
> 黛玉道：“据我看来，头一句好的是‘圃冷斜阳忆旧游’，这句背面傅粉。……”
> 探春又道：“到底要算蘅芜君沉着……”
> 宝钗笑道：“你的‘短鬓冷沾’，‘葛巾香染’，也就把簪菊形容的一个缝儿也没了。”

**注意结构**：李纨定名次（公评），然后**每个人评的是别人的好句，不是自己的**。黛玉评宝钗、探春评宝钗、宝钗评探春、湘云评黛玉。

**全书凡写"才"，一律写"识得别人的才"。** 这一条比任何"她才情高"的形容都硬——癸酉本写才子才女，一律让人自己作完自己夸。

## h039　村姥姥是信口开合　情哥哥偏寻根究底

**场景类型**：日常起居／说书（刘姥姥编故事）／单线（茗烟找庙）

**开场**：`话说众人见平儿来了，都说：“你们奶奶作什么呢，怎么不来了？”` —— 承接上回末（平儿进园），从一个人的到场接住。

**骨架**：
平儿来取螃蟹 → 李纨拉平儿坐、灌酒，论各房大丫头（鸳鸯、彩霞、袭人）→ 李纨提贾珠，落泪 → 平儿向袭人透露凤姐拿月钱放利 → 刘姥姥二进荣国府，送枣子倭瓜野菜 → 周瑞家的报贾母要见 → 平儿替小厮应假 → 见贾母，互道年纪，贾母自称"老废物" → 刘姥姥编"雪下抽柴"故事 → 南院马棚失火，故事被打断 → 再编"观音送孙"故事 → 宝玉私下追问，刘姥姥胡诌"茗玉小姐" → 宝玉派茗烟去找庙 → 找到的是青脸红发的瘟神爷

**句法样本**：
1. `那刘姥姥虽是个村野人，却生来的有些见识，况且年纪老了，世情上经历过的，见头一个贾母高兴，第二见这些哥儿姐儿们都爱听，便没了说的也编出些话来讲。`（"见头一个……第二见……"——**把说书人当场调整策略的过程写出来了**，这是全书对"讲故事"最自觉的一笔）
2. `我们生来是受苦的人，老太太生来是享福的。`（对照句，一句两个人；刘姥姥的奉承永远是这种对句，从不说单句好话）

**标签样本**：
- 笑道：`刘姥姥笑道：“这正是老太太的福了。我们想这么着也不能。”`
- 其他（自嘲，且是真话）：`贾母道：“什么福，不过是个老废物罢了。”`
- 其他（顶撞）：`茗烟拍手道：“那里有什么女孩儿，竟是一位青脸红发的瘟神爷。”`

**独有瞬间**：
> 宝玉听了，啐了一口，骂道：“真是一个无用的杀才！这点子事也干不来。”
> 茗烟道：“二爷又不知看了什么书，或者听了谁的混话，信真了，把这件没头脑的事派我去碰头，怎么说我没用呢？”
> 宝玉见他急了，忙抚慰他道：“你别急。改日闲了你再找去。”

**点评**：**全书唯一一次下人当面顶撞宝玉，而且说得他无言。** 茗烟这一句把整件事点破：不是我没用，是你信了个编的故事。

宝玉"见他急了，忙抚慰他"——**他被说服了，但一个字没承认。** 这个处理极准：他不认错，只是不再追究。全书宝玉的"认错"都是这个样子，从不道歉，只转移。

**这一回的真正结构：同一个故事，三个人听见三样东西。**

| 听的人 | 听见什么 | 为什么 |
|---|---|---|
| 贾母 | "积古的老人家说话儿" | 解闷 |
| 王夫人 | "吃斋念佛，观音送孙" | 正合心事——贾珠死了，宝玉是她唯一的 |
| 宝玉 | "十七八岁的极标致的小姑娘" | 当真，要去修庙塑像 |

**一段编造的故事，被三种需求各自截取一段。** 而讲故事的人当场看出谁要什么，随时调整——`见头一个贾母高兴，第二见这些哥儿姐儿们都爱听，便没了说的也编出些话来讲`。

**这是全书写"信息如何被需求塑造"最狠的一回。** 刘姥姥不是骗子，她是一个精确的供给者。

**第三处（火，插在故事中间）**：
> 刚说到这里，忽听外面人吵嚷起来……丫鬟回说“南院马棚里走了水”。

故事讲到"穿着大红袄儿，白绫裙子——"就断了。**一个"红"字接一场火。** 这是全书最精巧的一次场景缝合：讲的是雪里红衣，烧的是马棚。贾母"足的看着火光息了方领众人进来"——**她信的不是故事，是火。**

## 本批横向观察

1. **写"才"要写"识得别人的才"。** h038 评诗，五个人评的全是别人的好句。全书凡写才情，一律通过"赞别人"完成，从不自夸。**这一条直接判掉癸酉本里人物自述才华的段落。**

2. **等级在最放松的时刻才显形。** h038 平儿抹了凤姐一脸蟹黄，全场大笑。**同一回里，凤姐站着伺候、李纨凤姐的席是"虚设坐位"、丫头们另摆一桌——等级一刻没停，只是被笑声盖住了。**

3. **对句是刘姥姥的语言公式。** "你们生来是受苦的人／老太太生来是享福的"、"我们想这么着也不能／这正是老太太的福"。**她的每一次奉承都是把两个人摆成一对。** 这是村妇的修辞，也是她唯一的安全策略——抬高对方的同时不高抬自己。

4. **一个故事，三种需求各取一段。** h039 是本批最重要的一回：同一段编造，贾母取"解闷"、王夫人取"送孙"、宝玉取"少女"。**作者不评判谁信谁不信，只让三个人各自拿走自己要的。**

5. **误中副车（写群戏的高级手法）。** h038 平儿要抹琥珀，抹到凤姐；h039 刘姥姥讲红衣，讲出火灾。**两处都是"打偏了"，而打偏的结果比打准更有戏。** 癸酉本的群戏一律"该打谁就打谁"，从无偏差。

6. **下人顶撞只有一次，而且是用逻辑顶的。** h039 茗烟："二爷又不知看了什么书，或者听了谁的混话，信真了……怎么说我没用呢？"**全书下人反驳主子，只有这一处说得主子无话。** 其余的顶撞全是情绪（晴雯撕扇、金钏回嘴），只有茗烟这一处是讲理。

7. **时令刻度**：h038 用"桂花"开、h039 用"枣子倭瓜并些野菜"起。**全书凡换季，一律用作物或花木报时，不用"到了秋天"这种话。** 八月＝桂花＋螃蟹；秋末＝倭瓜枣子。

8. **时间推进词本批实录**：`一宿无话`、`一时`、`至午`、`少顷`、`次日一早`、`好容易等到日落`、`说着`、`不在话下`。**`好容易等到日落`是本批唯一带情绪的时间词**——时间长度由等人的焦急量出来，不由钟点。

9. **叙述者本批显身 0 次。** 两回全部由人物行动推进。至此外部统计与逐回亲读仍是完全一致。
