# 亲读笔记 · 第 10–13 回

> 本人逐字通读。按用户指示，回目、诗词、批语不入蒸馏，只记行文。

---

## h010 金寡妇贪利权受辱 张太医论病细穷源（约 7,000 字）

**场景**：日常起居＋探病私谈＋议论

**开场**：`话说金荣因人多势众，又兼贾瑞勒令，赔了不是`——承接上回斗殴收场。

**骨架**：金荣回家抱怨 → 胡氏算账劝忍（七八十两银子的账）→ 璜大奶奶怒起，坐车赴宁府 → 尤氏一段近千字独白述病 → 金氏盛气消散 → 张友士论脉断病 → 开方

**句法样本**
- `一面叫老婆子瞧了车，就坐上往宁府里来。`
- 尤氏独白用「我说……他说……我说……」三层转述，一个人替全家说话（`我说他：'你且不必拘礼……'连蓉哥我都嘱咐了，我说：'你不许累掯他……'`）

**标签样本**：`笑道`（张友士两处：`那先生笑道："大奶奶这个症候，可是那众位耽搁了。"`）；本回**无一处冷笑**；`叹道`（尤氏）

**独有瞬间**：`把方才在他嫂子家的那一团要向秦氏理论的盛气，早吓的都丢在爪洼国去了。`——用地理名词写心理消散，一句顶一段心理描写。

## h011 庆寿辰宁府排家宴 见熙凤贾瑞起淫心（约 8,000 字）

**场景**：宴饮＋探病＋巡览

**开场**：`话说是日贾敬的寿辰，贾珍先将上等可吃的东西、稀奇些的果品，装了十六大捧盒`——「话说」挂名，实为器物直入。

**骨架**：送食盒去玄真观 → 客至、席上说病 → 凤姐宝玉探秦氏 → 宝玉落泪被劝出 → 凤姐独行园中遇贾瑞 → 天香楼点戏 → 回府瞒贾母

**句法样本**
- `一面说着，一面拿眼睛不住的觑着凤姐儿。`
- `凤姐儿故意的把脚步放迟了些儿，见他去远了，心里暗忖道`

**标签样本**：`笑道`（凤姐对贾瑞两次「假意含笑」）；`哼了一声`（对平儿，全回最冷的一记，却不用「冷笑」）

**独有瞬间**：`黄花满地，白柳横坡。小桥通若耶之溪，曲径接天台之路。`——正要出事，偏先铺一段最工整的骈赋。景越美，人越脏。

## h012 王熙凤毒设相思局 贾天祥正照风月鉴（约 7,500 字）

**场景**：口角争执＋梦幻神异

**开场**：`话说凤姐正与平儿说话，只见有人回说："瑞大爷来了。"`——承接上回末句「等他来了，我自有道理」。

**骨架**：贾瑞来访 → 约穿堂、冻一夜 → 代儒打三四十板、罚跪风地读书 → 再约空屋 → 贾蓉贾蔷索欠契各五十两 → 净桶尿粪浇头 → 病 → 跛道赠鉴 → 正照而死

**句法样本**
- `一面到了自己房中更衣洗濯，心下方想到是凤姐顽他。`
- `倏又腊尽春回，这病更又沉重。`——四个字跳一季

**标签样本**：`笑道`（凤姐对贾瑞全程「笑道」，一处冷笑也无）；`骂道`（`道士混帐，如何吓我！`）

**独有瞬间**：`谁叫你们瞧正面了！你们自己以假为真，何苦来烧我？`——让一面镜子开口，替作者下判词，且是全书唯一一次器物说话。

## h013 秦可卿死封龙禁尉 王熙凤协理宁国府（约 8,000 字）

**场景**：梦幻神异＋丧葬诀别＋官司（捐官）

**开场**：`话说凤姐儿自贾琏送黛玉往扬州去后，心中实在无趣`——承接上回黛玉登舟。

**骨架**：夜梦秦氏赠言（置田、家塾二事）→ 云板四下、死讯 → 宝玉喷血奔丧 → 贾珍「尽我所有」→ 樯木棺材 → 戴权卖龙禁尉（一千二百两）→ 僧道对坛 → 宝玉荐凤姐 → 凤姐理出五弊

**句法样本**
- `因忽又听得秦氏之丫鬟名唤瑞珠者，见秦氏死了，他也触柱而亡。`
- `一面吩咐去请钦天监阴阳司来择日`

**标签样本**：`含笑说道`（秦氏入梦第一句 `婶子好睡！我今日回去，你也不送我一程。`）；`冷笑道`（`婶子好痴也。`）

**独有瞬间**：`只听二门上传事云板连叩四下，将凤姐惊醒。`——死讯不用人报，用制度性的四声云板报。梦与丧之间不留一句过渡。

---

## 本批小结

- **四回全部承接开场**，无一处景物起笔、无一处设问。
- **冷笑的缺席值得记**：h010、h011、h012 三回几乎无「冷笑」，凤姐对贾瑞三回通篇「笑道」——**越要人命，脸越和软**。冷笑只在 h013 秦氏口中出现一次（`婶子好痴也`），那是托梦，不是人间。
- **心理描写一律外化**：`丢在爪洼国去了`（h010）、`身上已木了半边`（h011）、`如得珍宝`（h012）、`如万箭攒心`（h011）。没有一处写「他感到」。
- **时间压缩靠成语四个字**：`倏又腊尽春回`（h012）、`闲言少叙`（h013）。**不用「堪堪」「倏忽」以外的长句交代。**
