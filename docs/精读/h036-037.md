## h036　绣鸳鸯梦兆绛芸轩　识分定情悟梨香院

**场景类型**：日常起居／私谈（宝钗代刺）／单线（龄官与贾蔷）

**开场**：`话说贾母自王夫人处回来，见宝玉一日好似一日，心中自是欢喜。` —— 承接上回（伤渐愈），随即交代贾母下令：`过了八月才许出二门`。一句命令，把宝玉从社交场里彻底摘出来。

**骨架**：
贾母吩咐免宝玉应酬 → 宝玉越发纵性，除四书外竟焚书 → 凤姐与平儿议丫头月钱（金钏空缺，几家来钻）→ 王夫人把一两银子给玉钏，又自掏分例给袭人 → 凤姐廊下骂那些抱怨的人 → 宝钗入怡红院，院中无人皆睡 → 袭人绣鸳鸯兜肚，宝钗不留心坐下代刺 → 黛玉、湘云窗外看见，一个忍笑一个拉走 → 宝玉梦中喊"什么是金玉姻缘，我偏说是木石姻缘" → 袭人得王夫人分例 → 宝玉论死（文死谏武死战）→ 梨香院，龄官拒唱 → 贾蔷买雀儿，龄官哭"牢坑" → 宝玉悟"各人各得眼泪"

**句法样本**：
1. `不想一入院来，鸦雀无闻，一并连两只仙鹤在芭蕉下都睡着了。`（"连……都"，用一个不该睡的东西写静；全书写"极静"一律拉一只鸟兽下水）
2. `只见宝玉穿着银红纱衫子，随便睡着在床上，宝钗坐在身旁做针线，旁边放着蝇帚子。`（三个并列结构，一个画面三重信息，**不加一句评语**；这一句是全回的分量所在）

**标签样本**：
- 笑道（悄悄）：`宝钗走近前来，悄悄的笑道：“你也过于小心了，这个屋里那里还有苍蝇蚊子，还拿蝇帚子赶什么？”`（全回多人低声，"悄悄笑道"是这一回的基础音量）
- 冷笑道：`袭人听了，便冷笑道：“你倒别这么说。从此以后我是太太的人了，我要走连你也不必告诉，只回了太太就走。”`
- 其他（梦中喊骂）：`宝玉在梦中喊骂说：“和尚道士的话如何信得？什么是金玉姻缘，我偏说是木石姻缘！”`

**独有瞬间**：
> 林黛玉见了这个景儿，连忙把身子一藏，手握着嘴不敢笑出来，招手儿叫湘云。湘云一见他这般景况，只当有什么新闻，忙也来一看，也要笑时，忽然想起宝钗素日待他厚道，便忙掩住口。知道林黛玉不让人，怕他言语之中取笑，便忙拉过他来道：“走罢。”……林黛玉心下明白，冷笑了两声，只得随他走了。

**点评**：三个人在窗外，三种反应，全部无声——黛玉"手握着嘴不敢笑"（恶意的乐），湘云"忙掩住口"（善意的护），然后编个借口把人拉走。

**没有一句台词交代她们的立场，全靠"掩口"和"拉走"两个动作。** 而黛玉那声"冷笑了两声"，是她明白湘云在护宝钗——**她笑的是这层掩护，不是宝钗的针线。**

技术核心：**用"谁拉住谁"写阵营。** 全书凡多人同场，阵营从不说明，一律由"谁跟谁走、谁拉谁走"交代。

**第二处（全书最重的一句宣言，由梦话完成）**：
> 忽见宝玉在梦中喊骂说：“和尚道士的话如何信得？什么是金玉姻缘，我偏说是木石姻缘！”薛宝钗听了这话，不觉怔了。

最重的表态，在**睡着、不知情、当着宝钗的面**说出来；最重的反应，只有`怔了`两个字。

**曹雪芹的安排极狠**：这句话不能让宝玉醒着说（醒着就是表白，就俗），必须由梦说；而听的人必须是宝钗本人。**一句话同时完成"表态"和"伤人"，且当事人无从辩解。**

**第三处（宝玉论死，全书价值宣言）**：
> 那些个须眉浊物，只知道文死谏，武死战，这二死是大丈夫死名死节。竟何如不死的好！……可知那些死的都是沽名，并不知大义。

**句式值得记**：先立"世人的说法"，再逐条拆（文官如何、武将如何），最后给结论。**立—拆—断**三段。这是宝玉每一次"怪论"的固定结构（h031 论爱物同式）。

**第四处（龄官一段，全书写"情"的转折点）**：
> 龄官道：“你们家把好好的人弄了来，关在这牢坑里学这个劳什子还不算，你这会子又弄个雀儿来，也偏生干这个。你分明是弄了他来打趣形容我们，还问我好不好。”贾蔷听了，不觉慌起来，连忙赌身立誓。

买雀儿是为哄她开心，她看见的是"笼子"。**同一个物件，两个人看见两样东西。** 贾蔷的用心越诚，伤她越深——这是全书最经济的一次"好意伤人"。

而宝玉在旁边看完全程，`不觉痴了，这才领会了划"蔷"深意`，回去就说：`昨夜说你们的眼泪单葬我，这就错了。我竟不能全得了。从此后只是各人各得眼泪罢了。`

**宝玉的"情"在这一回收了边界。** 从"所有女儿的眼泪都归我"，到"各人各得"。这是他全书唯一一次真正长进，且由一个外人（龄官）的恋爱教会他，不由任何说教。

## h037　秋爽斋偶结海棠社　蘅芜苑夜拟菊花题

**场景类型**：诗社雅集（起社）／私谈（宝钗与湘云夜拟题）

**开场**：`这年贾政又点了学差，择于八月二十日起身。` —— 全书极少见的"以时令大事开篇"。**一句把贾政支走**，园中才有诗社。此后凡园中盛事，必先写贾政不在。

**骨架**：
贾政点学差出门 → 探春花笺邀社 → 贾芸送白海棠并帖子（自称"男芸"，认父）→ 众人聚秋爽斋议起社 → 起别号：稻香老农、蕉下客、潇湘妃子、蘅芜君、富贵闲人、菱洲、藕榭 → 李纨自荐掌坛，定两位副社长 → 迎春限韵：抽书得七律、丫头随口说"门"字 → 各作白海棠诗 → 李纨评：蘅稿第一、潇稿第二、宝玉压尾 → 定社名"海棠社"，每月初二、十六 → 袭人打点送湘云：玛瑙碟、红菱鸡头、桂花糖蒸新栗粉糕 → 晴雯秋纹麝月闲话（太太赏衣、"哈巴儿"）→ 湘云来，和诗两首 → 宝钗邀湘云同住，替她设螃蟹宴 → 夜拟菊花十二题、编定次序

**句法样本**：
1. `独黛玉或抚梧桐，或看秋色，或又和丫鬟们嘲笑。`（三个"或"写她不作诗的样子，与众人"悄然各自思索"直接对照；**用"不参与"写参与**）
2. `原来这“梦甜香”只有三寸来长，有灯草粗细，以其易烬，故以此烬为限，如香烬未成便要罚。`（把时间量化成一支香；全书凡写"限时"一律用实物，不用"一炷香工夫"这种套语）

**标签样本**：
- 笑道：`黛玉笑道：“你们快牵了他去，炖了脯子吃酒。”`
- 冷笑道：`晴雯冷笑道：“虽然碰不见衣裳，或者太太看见我勤谨，一个月也把太太的公费里分出二两银子来给我，也定不得。”`
- 其他（啐骂）：`晴雯笑道：“呸！没见世面的小蹄子！那是把好的给了人，挑剩下的才给你，你还充有脸呢。”`

**独有瞬间**：
> 黛玉笑道：“古人曾云‘蕉叶覆鹿’。他自称‘蕉下客’，可不是一只鹿了？快做了鹿脯来。”众人听了都笑起来。
>
> 探春因笑道：“你别忙中使巧话来骂人，我已替你想了个极当的美号了。……如今他住的是潇湘馆，他又爱哭，将来他想林姐夫，那些竹子也是要变成斑竹的。以后都叫他作‘潇湘妃子’就完了。”

**点评**：全书黛玉最"文人"的一次玩笑——用典、拆字、当场把人变成一道菜。探春的反击立刻就来，而且更狠：不还嘴，直接给她定一个号。

**"潇湘妃子"是全书最大的伏笔之一**：娥皇女英哭舜，泪洒竹上成斑。黛玉的结局就在这个号里——**而这个号是在一场玩笑里被起的，被起的人"低了头方不言语"。**

一句玩笑定终身，且当事人当时就沉默了。**这是全书埋谶的标准方式：不由算命先生、不由判词，由一场闲话。**

**第二处（宝钗替湘云设宴，全书写"人情"最细的一段）**：
> 宝钗道：“……你家里你又作不得主，一个月通共那几串钱，你还不够盘缠呢。这会子又干这没要紧的事，你婶子听见了，越发抱怨你了。……我们当铺里有个伙计，他家田上出的很好的肥螃蟹……你如今且把诗社别提起，只管普通一请。”
>
> 宝钗又笑道：“我是一片真心为你的话。你千万别多心，想着我小看了你，咱们两个就白好了。”

**她解决的不是"没钱"，是"没钱还要体面"。** 三步：先替对方把难处说破（不让她自己承认），再给一个不花钱的名目（赏桂花，不提诗社），最后预先拆掉"你看不起我"这层疑心。

**这比直接给钱难十倍。** 全书凡写宝钗"会做人"，用的都是这个三步法，没有一次是单纯施舍。

**第三处（晴雯、秋纹、麝月那段闲话，技术极高）**：
> 秋纹笑道：“……太太越发喜欢了，现成的衣裳就赏了我两件。……却不像这个彩头。”
> 晴雯笑道：“呸！没见世面的小蹄子！那是把好的给了人，挑剩下的才给你，你还充有脸呢。”
> ……
> 众人听了都笑道：“骂的巧，可不是给了那西洋花点子哈巴儿了。”
> 袭人笑道：“你们这起烂了嘴的！得了空就拿我取笑打牙儿。”

三个丫鬟一台戏：秋纹炫耀（得衣裳）、晴雯贬损（剩的才给你）、众人把话绕到袭人身上（"哈巴儿"）——**一场闲话同时完成三件事：写秋纹的浅、写晴雯的刺、写袭人在屋里的位置（被暗指，且她自己接住）。**

全回没有一个字说"丫鬟之间有等级"，靠一件赏的衣裳和一句绰号说完了。

## 本批横向观察

1. **最重的表态由梦话完成。** h036 宝玉梦中喊"木石姻缘"，宝钗"怔了"。醒着说就是表白（俗），梦着说才是命。**全书凡最要紧的话，都要绕开"当事人清醒地说"这一条。**

2. **阵营由"谁拉谁走"交代。** h036 湘云拉走黛玉，黛玉"心下明白"；h035 袭人拉走莺儿（怕她没意思）。**没有一次写"她们是一伙的"，全靠动作。**

3. **玩笑里埋谶。** h037"潇湘妃子"由探春一句玩笑定下，黛玉"低了头方不言语"。**全书判词之外的重要伏笔，多半在闲话里。** 这一条对润色极重要：癸酉本凡埋伏笔必用郑重语气，正好相反。

4. **好意伤人。** h036 贾蔷买雀儿哄龄官，龄官看见的是"牢坑"。**同一个物件两个人看见两样东西**，用心越诚伤得越深。全书冲突的最高形式不是恶意，是错位。

5. **限时用实物，不用套语。** "梦甜香三寸来长，灯草粗细"（h037）。全书凡"一炷香工夫""一盏茶时"这类套语用得极少，能具体就具体。

6. **宝玉的"情"在这一批收了边界。** 从"你们的眼泪单葬我"到"各人各得眼泪"（h036）。全书唯一一次真正的成长，且由外人的恋爱教会他，不由说教。**这条直接否掉癸酉本"人物靠顿悟升级"的写法。**

7. **时间推进词本批实录**：`这日午间`、`一日`、`次日一早`、`至晚`、`少站片时`、`一时`、`当下`、`不在话下`。**h037 开头用"这年贾政又点了学差"这种"年"级刻度开篇**，全书仅数处，都用于"长时间跨度后重启叙事"。

8. **叙述者本批显身 0 次。** 两回全部由人物行动与对话推进，无一处"看官""试想"。至此外部统计与逐回亲读完全一致：**80 回 8 处显身，全部落在换轨处，情节段落一次没有。**
