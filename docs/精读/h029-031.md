## h029　享福人福深还祷福　痴情女情重愈斟情

**场景类型**：庙会巡览（清虚观）／口角（宝黛砸玉）

**开场**：`话说宝玉正自发怔，不想黛玉将手帕子甩了来，正碰在眼睛上` —— 承接上回末句（帕子甩脸），一字不绕地接住。

**骨架**：
凤姐约看戏 → 贾母同去 → 初一清虚观，车队"乌压压的占了一街" → 凤姐打小道士，贾母怜惜 → 贾珍训贾蓉，命小厮啐他脸 → 张道士为宝玉说亲 → 神前拈戏三本（《白蛇记》《满床笏》《南柯梦》），贾母不言语 → 贺物中见金麒麟，黛玉刺宝钗"留心" → 宝玉揣麒麟 → 次日宝黛口角：砸玉、剪穗、四人同哭 → 贾母"不是冤家不聚头"

**句法样本**：
1. `贾母坐一乘八人大轿。李氏、凤姐儿、薛姨妈每人一乘四人轿。宝钗、黛玉二人共坐一辆翠盖珠缨八宝车。迎春、探春、惜春三人共坐一辆朱轮华盖车。`（一句一车，按人等分派；轿、车的规格与共乘人数**就是等级表**，不用一句说明）
2. `这个说“我不同你在一处”，那个说“你压了我们奶奶的包袱”，那边车上又说“蹭了我的花儿”，这边又说“碰折了我的扇子”，咭咭呱呱，说笑不绝。`（四个指示词＋四句口语，一句一景，用声音把一条街填满）

**标签样本**：
- 笑道：`凤姐儿笑道：“我们爷儿们不相干。他怎么常常的说我该积阴骘，迟了就短命呢！”`
- 冷笑道：`林黛玉冷笑道：“他在别的上还有限，惟有这些人带的东西上越发留心。”`
- 其他（打骂）：`凤姐便一扬手，照脸一下，把那小孩子打了一个筋斗，骂道：“野牛肏的，胡朝那里跑！”`（"一扬手""照脸""一个筋斗"，三个动作定住一巴掌）

**独有瞬间**：
> 贾珍道：“你瞧瞧他，我这里也还没敢说热，他倒乘凉去了！”喝命家人啐他。那小厮们都知道贾珍素日的性子，违拗不得，有个小厮便上来向贾蓉脸上啐了一口。贾珍又道：“问着他！”那小厮便问贾蓉道：“爷还不怕热，哥儿怎么先乘凉去了？”贾蓉垂着手，一声不敢说。

**点评**：父子之间的权力，靠一个下人啐少爷的脸来完成。**父亲不下手，让奴才下手；儿子不能回嘴，只能"垂着手"。** 羞辱的效率写在程序里，不写在表情里。这比任何"贾珍严厉"的形容都重。

**同回第二处**：贾母听第三本《南柯梦》，`便不言语`。三个字。前两本她还说话（"这倒是第二本上？也罢了"），第三本一句不言语。**全书的命运预告，用一个沉默完成**，没有任何解释、没有一句"贾母心中暗惊"。

**第三处（全书最好的群哭）**：
> 袭人见他两个哭，由不得守着宝玉也心酸起来……不如大家一哭，就丢开手了，因此也流下泪来。紫鹃……见三个人都鸦雀无声，各人哭各人的，也由不得伤心起来，也拿手帕子擦泪。四个人都无言对泣。

四个人哭，四种理由：宝玉悔、黛玉委屈、袭人无处劝、紫鹃跟着伤心。**同一种生理反应，四份不同的因。** 这是"对位"手法用在情绪上，癸酉本一次也没有。

## h030　宝钗借扇机带双敲　龄官划蔷痴及局外

**场景类型**：口角（宝钗双敲）／日常（金钏被撵）／单线（龄官划蔷）／误会（踢袭人）

**开场**：`话说林黛玉自与宝玉口角后，也自后悔，但又无去就他之理，因此日夜闷闷，如有所失。` —— 承接上回，且**用"无去就他之理"五字说明她为什么不动**，一句写出全部处境。

**骨架**：
紫鹃劝黛玉 → 宝玉赔不是，说出"你死了，我做和尚" → 黛玉戳额、摔帕 → 凤姐拉去贾母处 → 宝玉奚落宝钗"体丰怯热" → 宝钗借靛儿发火，用"负荆请罪"双敲 → 凤姐"吃生姜"补一刀 → 王夫人午睡，宝玉调金钏 → 王夫人打金钏、撵出 → 蔷薇架下，龄官画"蔷"几千个 → 大雨，宝玉只顾别人淋雨 → 回院踢门，误踢袭人 → 袭人吐血

**句法样本**：
1. `宝玉笑道：“你死了，我做和尚！”林黛玉一闻此言，登时将脸放下来`（一句玩笑，立刻接一个"将脸放下来"，不加过渡、不写心理）
2. `只见这女孩子眉蹙春山，眼颦秋水，面薄腰纤，袅袅婷婷，大有林黛玉之态。`（四字短语连缀写貌，最后"大有林黛玉之态"作定性收口；全书写貌一律此式）

**标签样本**：
- 笑道：`宝钗笑道：“原来这叫作《负荆请罪》！你们通今博古，才知道‘负荆请罪’，我不知道什么是‘负荆请罪’！”`（同一句里把戏名重复三遍，重复即刀）
- 冷笑道：`宝钗……便冷笑了两声，说道：“我倒像杨妃，只是没一个好哥哥好兄弟可以作得杨国忠的！”`
- 其他（打骂）：`王夫人翻身起来，照金钏儿脸上就打了个嘴巴子，指着骂道：“下作小娼妇，好好的爷们，都叫你教坏了。”`

**独有瞬间**：
> 只见他虽然用金簪划地，并不是掘土埋花，竟是向土上画字。宝玉用眼随着簪子的起落，一直一画一点一勾的看了去，数一数，十八笔……原来就是个蔷薇花的“蔷”字。……只见那女孩子还在那里画呢，画来画去，还是个“蔷”字。再看，还是个“蔷”字。里面的原是早已痴了，画完一个又画一个，已经画了有几千个“蔷”。

**点评**：全书写痴情最狠的一段，而且**被看的人一句话都没有**。龄官从头到尾没开口，她全部的心事由"几千个蔷字"和一个"十八笔"的计数完成。宝玉在外面数笔画、猜字、看痴——**用旁观者的耐心，量出另一个人的痴。**

**结构上的第二处**：宝玉看别人淋雨，忘了自己也在雨里（`嗳哟了一声，才觉得浑身冰凉`）。这一笔把回目"痴及局外"落实了：他的痴不只对黛玉，是对所有受苦的人。不解释，只写一个迟到的知觉。

**第三处（宝钗的双敲，技术值得抄）**：
> 宝钗因见林黛玉面上有得意之态，一定是听了宝玉方才奚落之言，遂了他的心愿，忽又见问他这话，便笑道：“我看的是李逵骂了宋江，后来又赔不是。”宝玉便笑道：“……这叫《负荆请罪》。”宝钗笑道：“原来这叫作《负荆请罪》！你们通今博古，才知道‘负荆请罪’，我不知道什么是‘负荆请罪’！”

一句话同时打两个人：明说戏，暗指宝黛刚"赔不是"。**没有一个字骂人，两个人同时脸红。** 这是全书最高级的一次对话设计——冲突的全部信息藏在"她答的是什么戏"里。

## h031　撕扇子作千金一笑　因麒麟伏白首双星

**场景类型**：口角（晴雯）／日常／私谈（湘云翠缕论阴阳）

**开场**：`话说袭人见了自己吐的鲜血在地，也就冷了半截` —— 承接上回末句（吐血），并立刻补一句她此刻所想（`少年吐血，年月不保……争荣夸耀之心尽皆灰了`）。**这是全书第一次给袭人写"心"**。

**骨架**：
袭人见血，争荣之心尽灰 → 端阳宴众人无兴而散 → 宝玉跌扇，晴雯顶撞 → 袭人劝，晴雯咬住"我们"二字连她一起刺 → 宝玉要回太太撵晴雯，众丫鬟跪下 → 黛玉来打趣"好嫂子""作了两个和尚了" → 晚间宝玉回来，晴雯撕扇 → 次日湘云来，绛纹石戒指分赠四人 → 湘云翠缕论阴阳 → 蔷薇架拾金麒麟 → 宝玉丢了麒麟，湘云还他

**句法样本**：
1. `林黛玉天性喜散不喜聚。他想的也有个道理，他说，“人有聚就有散，聚时欢喜，到散时岂不清冷？”`（先给判断，再引本人的话作证——全书介绍人物观念的固定式，第 2 回冷子兴、第 5 回警幻都用同一结构）
2. `晴雯果然接过来，嗤的一声，撕了两半，接着嗤嗤又听几声。`（拟声词连用，"嗤""嗤嗤"，声音本身就是情节，不用一句"宝玉很高兴"）

**标签样本**：
- 笑道：`宝玉在旁笑着说：“响的好，再撕响些！”`
- 冷笑道：`晴雯冷笑道：“姐姐既会说，就该早来，也省了爷生气。自古以来，就是你一个人服侍爷的，我们原没服侍过。”`
- 其他（啐）：`湘云照脸啐了一口道：“下流东西，好生走罢。越问越问出好的来了！”`

**独有瞬间**：
> 晴雯听他说“我们”两个字，自然是他和宝玉了，不觉又添了醋意，冷笑几声，道：“我倒不知道你们是谁，别教我替你们害臊了！……明公正道，连个姑娘还没挣上去呢，也不过和我似的，那里就称上‘我们’了！”

**点评**：一场大吵，起因是**两个字**——袭人说了"我们"。全书最锋利的冲突都由一个词引爆："我们"（h031）、"金玉"（h028）、"好姻缘"（h029）。不写情绪升级，写**一个词语被对方抓住、反复咬住**。

这是可复制的技术：让矛盾落在一个具体的词上，然后让另一方把这个词单独拎出来质问。比写"她心里不舒服"强十倍，也最难被算法式的润色改掉——因为改掉那个词，整场戏就没了。

**第二处（宝玉的爱物论，全书价值宣言之一）**：
> 比如那扇子原是扇的，你要撕着玩也可以使得，只是不可生气时拿他出气。……这就是爱物了。

**注意它的句式**：先立"原是用来做什么的"，再让"玩"越过用途，最后划一条线"只是不可生气时拿他出气"。**立—越—划线**，三步。宝玉的每一次"怪论"都是这个三段式（第 19 回论女儿、第 36 回论死），不是散论。

**第三处（论阴阳，全书唯一一段"哲学对白"且全用大白话）**：
> 湘云道：“阴阳可有什么样儿，不过是个气，器物赋了成形。比如天是阳，地就是阴；水是阴，火就是阳；日是阳，月就是阴。”

翠缕一路追问，从天地问到蚊子跳蚤、树叶、扇子，最后问到"人有没有阴阳"，被湘云啐了一口。**把最抽象的一路话，交给一个最不懂的丫头来问**——这是全书讲道理的唯一有效方式：道理必须被一个不懂的人逼出来，否则就是作者在讲课。

## 本批横向观察

1. **等级不靠形容词，靠量词。** h029 八人大轿／四人轿／共坐一车；h025 席次；h028 节礼"多着一个香如意"。**同一件东西的规格差，就是人与人的位置差。** 全书没有一份"贾府等级表"，器物规格就是表。

2. **命运预告用沉默完成。** h029 贾母听《南柯梦》"便不言语"。同型还有 h022 贾政猜完灯谜"垂头沉思"。**两处都不写"心中大惊"，只写一个人不说话了。** 这是全书最稳定的高级手法，也是最容易被润色补坏的地方——加一句解释就全毁。

3. **冲突的引爆点是词，不是事。** "我们"（h031）、"金玉"（h028）、"好姻缘"（h029）、"负荆请罪"（h030）。四场大冲突全部由一个词触发。**写吵架要写被抓住的那个词。**

4. **群哭要写四份理由。** h029 宝黛袭紫四人同哭，各有各的因，一个"哭"字四种质地。这是"对位"手法用在情绪上。癸酉本凡群戏，所有人的反应一律相同。

5. **"痴"要用旁观者的耐心来量。** h030 宝玉数"蔷"字十八笔、看几千个；h023 黛玉把四处典故串成一条线。**两处都不写"她很痴情"，写有人花时间去数、去看、去想。**

6. **抽象必须由不懂的人逼出来。** h031 翠缕问阴阳，一路从天地问到跳蚤，最后被啐。h001 冷子兴演说、h002 贾夫人仙逝，都是同一结构：**道理由旁观者或外行问出来，不由主角宣讲。** 这一条直接判掉癸酉本大量"人物直接讲道理"的段落。

7. **时间推进词本批实录**：`一交五更`（h031，仅见）、`一时`、`至次日午间`、`这日正是端阳佳节`、`晚间回来`、`不在话下`。**`一交五更` 是全书极少见的精确报时**，与"一时""少时"这类模糊词分工：需要赶时间（请医、抓药）才用精确词。

8. **叙述者本批显身 0 次。** h029–h031 三回，全部由人物行动推进，无一处"看官""试想""此回则不能写"。与 h028"试想"、h017"诸公不知"形成对照：**换轨大段落才显身，情节推进段落一律退场。**
