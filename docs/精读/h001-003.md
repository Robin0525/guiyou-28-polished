## 第 1 回　甄士隐梦幻识通灵 贾雨村风尘怀闺秀（7,839 字）

**场景类型**：神话缘起 + 世俗小传（双线并置）

**开场**：议论起。"此开卷第一回也。作者自云：因曾历过一番梦幻之后，故将真事隐去……"——先以文言自述，第四段才转"列位看官：你道此书从何而来？"这是全书仅有的两次直接呼告读者之一（另一次在末回"看官听说"）。

**骨架**：作者自述 → 石头神话（僧道携石下凡）→ 绛珠还泪之约 → 甄士隐小传（梦、失女、火灾、投亲、出家）→ 贾雨村受赠赴京。
**这四层是套盒**：甄士隐是宝玉的缩小预演——同样"神仙一流人品"、同样遭家破、同样被跛足道人度走。

**句法样本**
- 承接：`原来`、`不想这日`、`真是闲处光阴易过，倏忽又是元宵佳节矣`
- 虚词密集：`士隐听了，不便再问。因笑道` / `便强从手中夺了去` / `遂易名为情僧` / `只得与妻子商议`
- 名词并置（全无动词）：`陋室空堂，当年笏满床；衰草枯杨，曾为歌舞场。`

**标签样本**：`笑道` 9 次，`道` 6 次。僧道对话一律"笑道"，连警告也是笑。

**独有瞬间**：僧道说"美中不足，好事多魔"八个字——全书主题用八个字说完，此后再不解释。

## 第 2 回　贾夫人仙逝扬州城 冷子兴演说荣国府（5,959 字）

**场景类型**：转述型（酒肆二人对谈，几乎无场景）

**开场**："却说封肃因听见公差传唤，忙出来陪笑启问。"——`却说`承接上回悬念，第一句就是动作。

**骨架**：封肃应传 → 娇杏扶正 → 雨村革职游历 → 林如海家世 → 智通寺老僧（一段闲笔）→ 冷子兴演说荣府谱系 → 正邪两赋论。
**关键手法**：家族谱系不由叙述者交代，借冷子兴之口说。作者退到幕后。

**句法样本**
- 议论长句（全书最长一段议论，300 余字）：`天地生人，除大仁大恶两种，馀者皆无大异。若大仁者，则应运而生……`
- 排比罗列人名，不厌其长：`尧、舜、禹、汤、文、武、周、召、孔、孟、董、韩、周、程、张、朱，皆应运而生者。`
- 转述中的直接引语：`他说："必得两个女儿伴着我读书，我方能认得字……"`——三层引语（作者→冷子兴→甄宝玉）

**标签样本**：`笑道` 8 次，`冷笑道` 2 次，`叹道` 3 次。二人对话几乎段段带笑，"冷笑道"只给冷子兴评宝玉时用。

**独有瞬间**：`偶因一着错，便为人上人。`——八字回目式反讽，把丫鬟一生的偶然写成判词。

## 第 3 回　贾雨村夤缘复旧职 林黛玉抛父进京都（8,578 字）

**场景类型**：人物出场（移动镜头，全书最典型）

**开场**："却说雨村忙回头看时，不是别人，乃是当日同僚一案参革的号张如圭者。"——`却说`+上回断点，一句话接住悬念。

**骨架**：雨村复职 → 黛玉登舟 → 入城 → 见贾母 → 见三姊妹 → 见凤姐 → 拜两舅 → 吃饭 → 宝玉出场 → 摔玉。
**结构即空间**：轿子走一路，叙事走一路，一道门一道门过，一步不跳。空间顺序就是叙事顺序。

**句法样本**
- `一面……一面` 密集：`黛玉一面吃茶，一面打谅这些丫鬟们` / `一面又问婆子们` / `一面命人到外面书房去请贾赦`
- 名物清单式白描（每院必写匾、陈设、椅搭）：`临窗大炕上铺着猩红洋罽，正面设着大红金钱蟒靠背，石青金钱蟒引枕，秋香色金钱蟒大条褥。`
- 判断句嵌在动作里：`黛玉度其位次，便不上炕，只向东边椅子上坐了。`

**标签样本**：`笑道` 21 次，`忙笑道` 4 次，`道` 12 次。凤姐一人占 `笑道` 六次，且"笑—哭—笑"三次转换在两百字内完成。

**独有瞬间**：`粉面含春威不露，丹唇未启笑先闻。`——先写声音后写人。全书写人物出场，只有凤姐是"未见其人，先闻其声"。

## 本批小结（可并入档案的增量）

1. **开场只有两式**：`话说/却说` + 上回断点；或开卷议论。三回无一次景物开场、无一次设问开场（除第一回那段"你道此书从何而来"，属作者自述体，非叙事开场）。
2. **时间推进不写年月**：`一日`、`次日`、`一时`、`不一时`、`须臾`、`堪堪又是`、`倏忽又是`、`真是闲处光阴易过`。没有一处"过了三个月"这种表述。
3. **铺垫靠"度"不靠"说"**：`黛玉度其位次`、`士隐心中此时自忖`、`雨村自为这女子心中有意于他`——人物判断一律用"度/忖/想/自为"，叙述者不下结论。
4. **`笑道` 是默认标签**：三回合计 38 次，占全部引语标签六成以上。
