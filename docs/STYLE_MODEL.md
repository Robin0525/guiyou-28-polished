# 风格模型：本项目的底层逻辑

这份文档是项目的基石。`data/style_model.json` 里的每一个数字，都是从这个模型的五个层里算出来的；润色与验收都对照它。

模型不是"我读过红楼梦所以有语感"，而是**可复算的统计结构**。理由见最后一节。

## 一、五层结构

| 层 | 测什么 | 数据文件 | 对应润色动作 |
|---|---|---|---|
| L1 功能词 | 36 个虚词的密度 | `style_model.json → L1` | 换词（`lexicon.tsv`） |
| L2 套语与句式 | 29 个框架的出现密度 | `patterns.tsv` | 改句式 |
| L3 引语动词 | 18 种"道"的分布 | `dialogue_tags.tsv` | 改对白标签 |
| L4 句长 | 均值、中位数、五档分布 | `style_model.json → L4` | 断句 |
| L5 声口 | 对白占比、人物语言档案 | `char_profiles.tsv` | 改人物腔调 |

运行：

```bash
python tools/build_style_model.py <hongloumeng.epub> data/
python tools/style_distance.py source/ drafts/ polished/ --out docs/风格距离.md
```

## 二、模型测出来的四件事（这是原来靠肉眼看不出的）

### 1. 「被」字句超用 5.7 倍

| | 每万字 |
|---|---|
| 校注本前80回 | 3.09 |
| 癸酉本后28回 | **17.62** |

曹雪芹极少用「被」。被动多用「叫」「让」「给」，或干脆用受事主语句（"这杯子叫人砸了"）。癸酉本满纸"被"，是二十世纪书面语的惯性。

这一条之前完全没发现——因为它不在"词汇"层，在语法层。

### 2. 「把」字句超用 2.6 倍

| | 每万字 |
|---|---|
| 校注本 | 10.59 |
| 癸酉本 | **27.89** |

同理。"把……"是现代汉语最顺手的处置式，清代白话更常用「将」，或者直接宾语前置。

### 3. 对白标签塌了：裸「道」翻倍，「笑道」腰斩

| 动词 | 校注本/万 | 癸酉本/万 |
|---|---|---|
| 道 | 34.59 | **72.29** |
| 笑道 | **26.74** | 14.66 |
| 说道 | 7.28 | 0.69 |

《红楼梦》里人人爱笑：**"笑道"几乎和裸"道"一样多**（26.74 vs 34.59）。癸酉本反过来，裸"道"占绝对多数，"笑道"只有一半，"说道"几乎不用（说明它不用"说道"，却又不见"笑道"，那就是一律裸"道"）。

这是最难伪装的一层。词汇可以抄，标签分布抄不了。

### 4. 长句比例翻倍

| 句长 | 校注本 | 癸酉本 |
|---|---|---|
| ≤10 字 | 13.5% | 8.7% |
| 11–20 字 | 35.4% | 27.9% |
| 21–30 字 | 26.6% | 24.6% |
| 31–40 字 | 13.2% | 16.0% |
| **>40 字** | **11.2%** | **22.9%** |

均值差只有 7.7 字，看着不严重；但分布尾部差一倍——癸酉本的毛病是**制造了大量超长句**，不是整体偏长。

### 附带结论：对白占比几乎一致

| | 对白占比 |
|---|---|
| 校注本 | 39.6% |
| 癸酉本 | 39.4% |

这条是"没有差异"的发现，同样重要：它说明癸酉本的**叙事节奏**（叙述与对白交替的比例）是像的。问题不在结构，在腔调。这修正了一个容易犯的误判——不能拿"结构不对"去否定它，只能拿语言。

## 三、第五件事：人物声口可以量化

`char_profiles.tsv` 是从校注本切出每位人物的话（`X笑道：“……”`），单独统计的。摘前九位：

| 人物 | 说话次数 | 平均句长 | 语气词/百字 | 主要标签 |
|---|---|---|---|---|
| 宝玉 | 318 | 27.9 | 1.77 | 道163、笑道125 |
| 凤姐 | 197 | 41.9 | 1.82 | 道85、笑道81 |
| 贾母 | 143 | 32.2 | 1.35 | 道66、笑道62 |
| 黛玉 | 126 | 29.9 | 1.38 | 道58、笑道51、**冷笑道5** |
| 宝钗 | 121 | **50.2** | **0.84** | 笑道58、道56 |
| 袭人 | 113 | 40.8 | 1.58 | 道60、笑道43 |
| 平儿 | 70 | 46.6 | 1.26 | 笑道32 |
| 湘云 | 68 | 30.4 | 1.06 | 笑道33 |
| 探春 | 66 | 49.7 | 0.97 | 道31、冷笑道5 |

这张表能读出曹雪芹的写法：**宝钗的话最长（50.2 字）而语气词最少（0.84）**——她讲道理，不撒娇；**黛玉短（29.9）且"冷笑道"最多**——尖；**凤姐居中偏长但"笑道"最高（81 次）**——场面人；宝玉句子最短（27.9）——孩子气、跳脱。

癸酉本每一回都用同一套算法切一遍，把同一个人物两张表并排看，就知道腔调跑没跑。这是精修时最实用的一张表。

## 四、由此定的四条改写原则

1. **减「被」**：被动改「叫／让／给」，或改受事主语句。目标 3–6/万。
2. **减「把」**：处置式改「将」，或宾语前置。目标 10–14/万。
3. **对白标签向「笑道」倾斜**：裸「道」降到 40/万 以下，「笑道」提到 20/万 以上。
4. **砍长句**：>40 字的句子压到 12% 以下，主要靠断句＋补「便」「一面」。

第 1、2 条是**新增的**，前一版词表里没有——因为当时只做了词汇层，没做语法层。

## 五、模型怎么用（精修工作流）

单回精修时：

```bash
python tools/style_distance.py polished/ drafts/ --out /tmp/x.md
```

看三张表：
- **L1 偏差前八**：先改偏差最大的虚词，收益最高。
- **L2 偏差前八**：找"该有却没有"的框架（如「一面…一面」「因…遂」），主动补。
- **L4 分布**：只看 `>40 字` 那一格，其他不用管。

改完再跑一次，偏离度下降为准。**不要看总分的绝对值**，只看同一稿本前后是否下降。

## 六、这个模型不能做什么

必须说清楚，否则就是拿统计冒充文学。

**能做到的**：把"像不像"拆成可复算的五个维度，让改动有据、让验收有数。上面四条发现，任何一条靠通读都读不出来。

**做不到的**：

1. **不能替代阅读。** 模型不知道"黛玉葬花"为什么动人，不知道哪句该留白。它只数词。
2. **不能保证自然。** 满足全部指标的文本，仍可能是"指标正确的假古董"。指标是下限，不是上限。
3. **L5 只到"每人平均句长＋语气词密度"这一层。** 真正的声口差异（黛玉的尖、宝钗的圆、凤姐的脆）是语义和策略层面的，统计抓不住。
4. **不能学。** 我没有在这个语料上训练任何模型，也无法把 75 万字装进上下文。所谓"学习"，在此项目里精确地指：**把可量化的部分抽成模型**，剩下的交给逐句改写。这是我能给的最诚实的版本。

所以项目的分工是：**模型管下限，人管上限**。`drafts/` 是模型能到的位置，`polished/` 是人力能到的位置，两者之间的差距就是这份工作真正的成本。
