# 回目·诗·批语 核验报告

本项目的规则是：**回目、诗、词、批语一字不改**，只重写行文。这份报告用来证明这一点，不是自述，是逐字比对的结果。

核验对象：`source/` 原稿中的回目、回前诗、正文诗、批语四类文本，
与 `polished/` 精修稿逐字比对（去空白后字符串完全相等才算通过）。

四类文本的判定口径：

- **回目**：`# 第……回` 整行；
- **回前诗**：「诗云：」之后、正文起始词（话说／且说／却说）之前的全部文字；
- **正文诗**：「吟道／念道／题曰／题诗／写道／诗曰／赋诗／词曰／曲曰」后引号内、含逗号且不短于十四字的内容（含引诗、联句、词曲）；
- **批语**：圆括号内不短于四字的注释，及方括号批。

**为什么只统计到这儿。** 上表四类文本共 275 处、约 7,600 字，是原稿中「不许动」的部分。其余约 21 万字是小说正文，允许且必须重写——那部分不在此核验范围，指标另见 [验收报告.md](验收报告.md) 与 [progress.md](../progress.md)。

**已登记的例外。** 引诗与后文叙述交界处的标点／语气词调整，诗本体未动，逐条列在上方「已登记的例外」中，并登记于本工具的 `KNOWN_EXCEPTIONS`。例外不隐藏，改一个字都要留痕。

**已知但不改的瑕疵。** 回目错字（「行狭义」「大瘐岭」）、批语误植（「如梗在喉」）、回前诗不合律（7 首韵脚平仄相杂），全部按原样保留，另见 [勘误与保留说明.md](勘误与保留说明.md)。
