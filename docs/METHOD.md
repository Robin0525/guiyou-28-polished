# 方法、口径与局限

## 一、流程

```
PDF ──extract.py──▶ source/*.md（原文，未改）
                        │
                   polish.py（规则层）
                        │
                        ▼
                  drafts/*.md（28/28 回，词汇+语气词）
                        │
                  人工精修（逐句重写）
                        ▼
                  polished/*.md
```

`check_style.py` 在三层都能跑，输出同一套指标，便于看每一步的收益。

## 二、为什么规则引擎只能做到一半

统计上能测出来的问题是两类：

**可机械修复的**——语气词、人称、现代词。共 39 条规则，一次替换到位。

**不可机械修复的**——「便」的密度、「一面」的并列结构、句长。这些不是词，是句式选择。把「于是」换成「便」并不会产生曹雪芹的句子，只会产生假的古白话；而且数据表明「于是」「然后」在基线里比癸酉本还多，根本不该换。唯一办法是重写句子。

所以本项目的产出是两层：`drafts/` 证明机器能做到哪一步，`polished/` 展示人能做到哪一步。两者不混。

## 三、口径

- 基线：红研所校注本**前八十回正文 590,940 字**（`corpus/` 分回文件，已剔注释与校记，不含换行符）。
- 旧法从 epub 直读得 753,918 字，其中 19.1% 是校注与校记，会把所有密度指标稀释，**已废止**；`build_baseline.py` 现只接受 `corpus/` 目录。电子版第十七、十八回按底本未分回，第五回标题格式异常，切分得 78 个回次，字数误差 <3%。
- 对象：后二十八回正文 234,600 字（不含回目、批语行）。
- 平均句长：按 `。！？；` 切分，剔除 ≤2 字碎片。
- 所有频次折为每万字。所有数字由 `tools/` 下脚本可复算。

## 四、诗词保护是怎么做的

两级：

1. **块级**：出现「诗云／词曰／回前批／批语／联句／对句」即进入保护态，直到遇到「话说／且说／却说」等叙述起头，或遇到含引号的对白行（诗词里不会有成对引号的对白）。
2. **行级**：长度 7–60 字、不含对话动词、按 `，、；：` 切分后各段长度多在 5/7 字，判为诗句。

宁可多保护。误保护的代价是漏改几句，误改的代价是把诗改坏——按项目规则，诗词一个字都不能动。

## 五、局限（重要）

**语言分析能证什么、不能证什么。**

能证：这二十八回的文字不是曹雪芹原文。语气词系统、套语密度、句长、用字习惯四项独立指标方向一致，且差异在数十倍量级。

不能证：仅凭语言不能断定"原本是曹雪芹写的、被过录者改坏了"。这个可能性逻辑上排除不掉。

但这条退路对该书不利。该书第 5—6 页自述：

> "目前已经无法从文字风格方面论证癸酉本的真假。"理由是姐姐过录时删去 1/4，剩下的 3/4 也经改动，"语言风格已迥异于原迹"。

等于自行放弃了文本举证。于是只剩情节可依，而情节恰是探佚结论的照抄。

**本项目的立场因此是**：不宣称"还原了曹雪芹"，只宣称"按前八十回的语言统计特征，把这个现代续书的行文调得更接近一档"。这是一次有指标的仿写练习，不是校勘。

## 六、已知副作用

- 「已经→已是」「一会儿→一回」等条目的替换是按词频方向做的，个别语境会不顺，需精修时逐句复核（标 M 风险的规则）。
- 规则对反问句、感叹句的语气词处理是启发式的，不保证句句自然。
- 原文本身有半角逗号、分号误用（如"宝玉泣道；"），抽取时未清理，精修时一并订正。
