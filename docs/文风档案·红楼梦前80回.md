## 核心风格签名（4 条，违反任何一条即不像）

1. **一切都用"便"串起来。** 43.61 次/万字，是癸酉本的 3 倍。曹雪芹的叙事不靠逻辑连接词，靠"便"——前一件事刚完，后一件事"便"发生。
2. **人物一开口先笑。** "笑道"33.39 次/万字，占全部引语标签 33%；裸"道"只占 44%。《红楼梦》里的人几乎都在笑，恼也笑，骂也笑，笑里带刀。
3. **句子短，且故意断在最难堪的地方。** 中位数 21 字，P90 43 字；>40 字只占 11.7%。断句点常常落在一个动作、一声称呼、一个不肯说完的半句上。
4. **不解释情绪，只给身体。** 不写"她很伤心"，写"两眼不觉滚下泪来""怔怔的望着他""只管发起呆来"。

## 开头切入必杀技库

《红楼梦》没有"小节"，扫描器的 18 个小节是签诗与诗题，不适用。改为按回目开场统计（78 回）：

| 切入方式 | 原文例句 | 适用场景 |
|---|---|---|
| **"话说/且说"＋前情一句带过** | 「话说莺儿见宝玉说话摸不着头脑，正自要走，只听宝玉又说道……」 | 默认动作，占绝对多数 |
| **接上回断点，动作先行** | 「且说过了几天便是场期，别人只知盼望他爷儿两个作了好文章便可以高中的了」 | 时间跳跃、场景切换 |
| **一语未了，只见某人来** | 「一语未了，只见麝月走来说：『太太打发人来告诉二爷，明儿一早往舅舅那里去。』」 | 制造插入、打断 |
| **以诗/签/谜起** | 「任是无情也动人。」 | 章内小高潮前 |

**绝不开头的方式**：定义式（"所谓……是指……"）、宏大背景式（"在……的时代背景下"）、设问式。全书没有一句这样的开头。

## 干货配比（改编自原维度）

小说没有"干货"，等价的硬信息是**具体名物**：

- **叙事 : 对白 : 诗词韵文** ≈ 54 : 46 : 少量（对白 46.0%）
- **名物密度**：一页之内常见三四样具体物件——"半旧红绫短袄""绿汗巾子""油绿绸撒花裤子""掐金满绣的绵纱袜子""蝴蝶落花鞋"。**这是文风的实体，不是装饰。**
- **对仿写的约束**：写人出场必须先给穿戴，写屋必须先给陈设；只写"华丽""精致"即翻车。

## 力量点指纹

- **转折引擎**：`原来`（补叙真相）、`谁知`/`岂知`（打翻预期）、`倒`（14.6 次/万字，最锋利的反诘副词）
- **强硬词**：极少绝对化。全书最硬的话都在人物嘴里，叙述者自己从不下判断
- **符号习惯**：不用破折号（正文 0.3 次/千字，几乎为零），不用省略号（0.2），感叹号极省（2.2/千字，约每 450 字一个）
- **现场感插入语**：`一语未了`、`说着`、`一面……一面`、`不在话下`、`自不必说`

## 节奏系统

- **推进机制**：账本式。一顿饭、一次探病、一场丧事，按时间顺序一件件记，记到某处忽然给一句重话（"如轰雷掣电"），然后立刻退回记账
- **偏题与回扣**：偏出去讲一个婆子的家常，回扣时只用一个动作（"说着，同周瑞家的引了刘姥姥往贾母这边来"）
- **断裂点**：极短句独立成段——「林黛玉不答。」「宝玉便不肯再说，只是剥栗子。」「黛玉啐道」
- **刹车与转向**：用"一语未了""忽听""只见"硬切，不用过渡句
- **句间衔接**：`便` / `因` / `一面……一面` / `说着`。**不用**"于是""然后""因此上"
- **句长节奏**：中位数 21 字；连续三个长句之后必有一个 ≤10 字的短句

## 禁区清单（可机械扫描）

**禁用词**（基线频次为 0 或近 0）：
`死翘翘` `老乡` `干活` `丢人` `搞定` `完蛋` `竟然` `居然` `肯定` `反正` `差点` `幸好` `一会儿` `被……所`

**罕用标点**：破折号（0.3/千字）、省略号（0.2/千字）。**正文几乎不用破折号。**

**禁用句式**：
- `被`字句（2.62/万字，是癸酉本的 1/7）。被动用"叫/让/给"或受事主语句
- `把`字句滥用（11.91/万字，癸酉本 27.89）。处置多用"将"
- 现代关联词链："因为……所以""虽然……但是"

**禁用姿态**：叙述者不评论、不总结、不点题。全书没有一句"这个故事告诉我们"。

## 叙事角度与姿态

- **叙述者**：全知，但刻意装傻——知道结局却不预告，只让人物自己走
- **人称/视角**：第三人称，视点随场景漂移，一段之内可从宝玉切到袭人再切到婆子
- **登味控制**：叙述者从不教育读者。判词、曲文把答案写在明面上，但绝不解说
- **判断力表达**：靠"对比"而非"评论"。同一件事让三个人各说一遍，谁高谁低自己看
- **对立面处理**：连赵姨娘、贾环也有可怜处；不设纯恶人

## 取材方式

- **素材来源**：亲历式的生活细节（贵族家日常）＋ 大量前代文本（《西厢》《牡丹亭》《庄子》）
- **细节密度**：极高，且精确到可复原——药方、份例、月钱、衣裳料子、行走路线（"过了蜂腰桥，撇过晓翠堂，往东一条甬道"）
- **编造容忍度**：零。一切名物必须真实可考，这是它最不能伪造的一层

## 风味与幽默机制

- **幽默类型**：冷幽默、反讽、人物自嘲（刘姥姥）、场面尴尬（贾政讲笑话）
- **口癖口头禅**：`罢了`（4.18/万字）、`不成`（句末反问）、`越发`、`索性`、`怪道`
- **情绪标点**：`！` 极省；情绪靠动作（"唿的一声，往后藏之不迭"）
- **彩蛋机制**：判词/曲文/诗谜预言后事，回环呼应；`草蛇灰线，伏脉千里`
- **只有曹雪芹会这么写的三个瞬间**：
  1. 宝玉诉肺腑，黛玉"如轰雷掣电……竟有万句言语，满心要说，只是半个字也不能吐"，随即"只咳了一声，两眼不觉滚下泪来，回身便要走"
  2. 贾政讲怕老婆的笑话，一屋子人笑，是因为"从不曾见贾政说过笑话"
  3. 黛玉笑宝玉是"那里来的渔翁"，紧接着细看他蓑衣下的裤袜鞋——笑完就转到针脚上

## 词汇层

- **核心意象域**：花（落花、葬花、花签）、水（沁芳溪、泪）、玉与石、窗与灯、雪与冷
- **雅俗配比**：叙述偏雅（文言残留在"遂""方""倒""竟"），对白全俗（"嚼什么蛆""睡的口头晒着屁股"）
- **禁忌词**：抽象名词（"情感""关系""氛围"）、现代度量（"分钟""公里"）、现代称谓（"老乡""女士"）

## 修辞与知识输出

- **比喻系统**：喻体取自闺阁与日常——"如轰雷掣电""像那刺猬似的""倒像黄鹰抓住了鹞子的脚"
- **高频手法**（排序）：白描 > 对比 > 反讽 > 用典 > 排比
- **引用习惯**：随手带出，不注明出处，且常借人物之口误引、改引（宝玉引《西厢》被黛玉骂）
- **知识输出方式**：聊着聊着顺手掏出来（药方、戏文、佛经），从不"下面我来科普"
- **升维方式**：从一件家常事接到佛道（"纵有千年铁门槛，终须一个土馒头"），连接极自然，因为人物本身就在那个语境里

## 情感温度

- **主导情绪**：悲凉底色上的热闹｜克制指数：**8/10**
- **情绪表达**：全部体感（"怔怔的""满面紫胀""魄消魂散"），没有一处"我感到非常……"
- **确定性**：叙述确定，人物不确定；结局已知，过程留白

## 结构与章法

- **原型**：章回体，每回一个中心事件 + 若干副线
- **结尾方式**：`要知端的——` / `且听下回分解` / 一句诗收 / 一个动作定格
- **叙事弧线**：由盛而衰，前八十回是"盛"的缓慢下坡，坡度极缓，靠无数小事的累积
- **对白占比 46.0%**，且对白承担全部性格塑造，叙述只负责场面

## 场景适配指南（改编：章内场景）

- **宴饮**：多用对白，短句多，穿插一人失言；席面名物要具体
- **丧葬**：叙述压过对白，句长放长，节奏放慢，几乎不用感叹号
- **口角**：句长骤短，`冷笑道` 高频，动作插入（"啐道""摔帘子"）
- **独处**：几乎无对白，全靠动作与心理，句长回到中位数
- **润色底线**：名物必须真、对白必须短、叙述者不许评论。这三条不可妥协
